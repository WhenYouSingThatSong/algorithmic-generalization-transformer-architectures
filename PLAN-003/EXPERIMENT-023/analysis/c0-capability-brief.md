# C₀ 能力与长循环漂移：实验简报

整理日期：2026-11-15。实验于2026-11-14完成；本说明仅整理现有数据，没有新增训练或模型运行。

## 1. 用了哪些权重

使用**旧C₀连续基线**：`C0-M4-Nodes32-ADD-L4H16D384-DeBERTa`，4层、16头、隐藏维度384；直接回灌hidden，无离散瓶颈、无专门纠错训练。训练数据为50,000张32节点图，最大依赖深度6，任务为模23加法。

| 权重简称 | 训练种子 | 本次实际checkpoint | SHA256前缀 |
|---|---:|---|---|
| s42_e143 | 42 | 150 epoch续训线的 `epoch=143-val_loss=0.0000.ckpt` | `4a00d6a21a7e` |
| s1234_e143 | 1234 | 同上，使用对应seed的e143权重 | `0bca3a2b91e8` |

不是新MixedN的C₀′，不包含s2025、新补种子或C⁺。完整权重路径与哈希见数据包 `runs/*/run_meta.json`。

## 2. 做了什么实验

- **数据：**N32/64/128 × 浅/深，共6档，每档64张图。两个权重使用同一批384张图，共768条“权重×图”轨迹，不是768张独立题目。
- **过程：**从题目初始状态（待求VALUE为空）开始，自由运行64轮；每轮回灌hidden，解码字段只用于记录。没有教师强制、人工注错、hidden替换或C⁺训练。
- **核心指标：**①节点VALUE正确率；②节点前四属性（SYNTAX、VARIABLE、OPERATION、VALUE）同时正确率。统计叶变量、内部变量及结果节点，排除常数、运算符和PAD；逐图等权。每档节点数固定，因此本表与节点加权一致。
- **过程指标：**是否曾整图VALUE全对，以及完成后保持、退化、恢复。64轮是观察上限，后期明显超出训练循环长度，主要考察长循环稳定性。

“浅/深”按实际最大依赖深度划分：N32浅4–6、深7–11；N64浅均为6、深7–12；N128浅均为6、深9–12。各规模没有严格匹配深度，不能把差异全部归因于节点数。

## 3. 得到了什么结果

表内为 **VALUE正确率 / 四属性同时正确率**。第16、64轮是观察截面，不代表已选定最佳停止轮次。

| 数据档 | s42，第16轮 | s42，第64轮 | s1234，第16轮 | s1234，第64轮 |
|---|---:|---:|---:|---:|
| N32 浅 | 100.00% / 99.61% | 96.83% / 9.86% | 99.85% / 96.09% | 93.26% / 9.33% |
| N32 深 | 99.17% / 98.63% | 93.75% / 9.42% | 99.95% / 95.21% | 90.92% / 8.15% |
| N64 浅 | 99.95% / 99.61% | 90.82% / 8.06% | 99.73% / 96.56% | 84.57% / 9.01% |
| N64 深 | 99.88% / 99.54% | 90.94% / 7.67% | 98.88% / 96.24% | 83.40% / 8.57% |
| N128 浅 | 99.65% / 99.39% | 89.25% / 8.04% | 99.30% / 96.75% | 70.29% / 8.04% |
| N128 深 | 99.93% / 99.78% | 81.93% / 7.24% | 98.32% / 95.98% | 64.25% / 6.71% |

全部正式轨迹中，所统计数值节点的SYNTAX和OPERATION均正确。因此，四属性指标比VALUE指标多出的损失来自VARIABLE读出错误。

| 完成与保持情况（整图VALUE口径） | 轨迹数 |
|---|---:|
| 曾达到全部节点数值正确 | 690 / 768 |
| 从首次完成后一直保持到第64轮 | 197 / 690 |
| 完成后再次出现数值错误 | 493 / 690 |
| 上述493条中，最后两轮重新达到整图数值全对 | 3 / 493 |

“3条恢复”是严格的整图VALUE指标，不是仅3个节点会恢复。690条完成轨迹中，没有一条从首次数值完成起始终保持全图VARIABLE正确。

## 4. 观察到什么现象

| 现象 | 真实案例 |
|---|---|
| **变量名漂移，数值仍保持** | s42 / N32浅 / 0000：第7轮全对；第64轮VALUE仍32/32正确，VARIABLE仅3/32正确。位置124读出由 `x_26` 变为 `x_71→x_33→x_24`，VALUE一直是1。 |
| **先名字漂移，随后数值退化** | s42 / N32浅 / 0002：第6轮全对，第20轮出现变量名错误；数值到第53轮仍全对，第54轮开始出错，第64轮剩23/32正确。 |
| **整图失败可能只是少量节点未算对** | s1234 / N128深 / 0002：始终未整图全对，但第14–22轮已有127/128节点数值正确；第64轮降到95/128。 |
| **存在数值自然恢复，属性未全部恢复** | s1234 / N32深 / 0047：第12轮数值全对，第49轮退化，第55–64轮数值再次全对；第64轮VARIABLE仅4/32正确。 |

493条同时出现数值退化和完成后VARIABLE新错误的轨迹中，VARIABLE先发生479条、同轮1条、VALUE先发生13条。这是时间关系，**不能证明变量名漂移导致数值错误**。

## 5. 当前判断与边界

1. **基础数值能力在本批节点指标上已较好，长循环保持能力明显不足。** 第16轮与第64轮应分开报告，不能只用长循环末轮表现判断模型会不会算。
2. **读出的变量身份与数值存在不同的稳定性。** 名字漂移不等于数值立即失效；尚不能断言模型内部已“忘记变量身份”。
3. **C⁺有可研究的故障：正确结果的保持、数值错误后的恢复。** 本批没有C⁺对照，不能据此声称某种纠错训练有效。
