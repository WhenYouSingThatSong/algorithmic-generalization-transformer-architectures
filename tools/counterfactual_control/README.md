# 通用同值 / 异值来源对照

2026-11-15。用户授权补齐来源对照，并明确不能只测4、5，要在不同数据与节点场景中构造通用情况。此实验不训练C+，不修改B或现有训练代码。

## 研究问题与操作

同一张原图中，目标u刚算出真实值a。构造三份不同题面，保持图结构、变量名、位置和序列长度不变，只改变同两个上游叶变量对应的题面常数：

- 同值来源：两处变化对u的贡献相互抵消，u仍为a。
- 异值来源1：两处变化使u变为(a+1) mod23。
- 异值来源3：两处变化使u变为(a+3) mod23。

例如u由两条上游路径的值相加得到，原值是17；同值来源仍算出17，异值来源分别算出18、20。遇到a=22则异值为0、2。**代码不按原值筛选，4→4和4→5只是这类操作的例子。**

对每份题面从原始token输入自由运行相同的d(u)+1轮，获得真实hidden。都从原图的同一份hidden起跑，只替换u这一行向量：不改、原样写回、同值来源、异值+1来源、异值+3来源。只改一次，随后连续运行16轮；全部用hidden回灌，解码字段仅观察。

另保留三份完整来源hidden的自由续算，按各自新题面真值评估。这是来源题的参考轨迹，不和“只换u”的干预混成一组。

## 怎样匹配来源

ADD mod23中，u对各叶值的系数等于叶到u的路径条数模23。搜索两个系数非零的祖先叶，使三份来源都改变这两个叶，且两处变化均非零。第一处的改变量在三份来源间相同；第二处分别满足u总变化0、1、3。按固定规则优先选最大模距离较小的组合，记录全部系数、叶位置、题面常数位置、改变量及新真值。

这匹配了改动位置和次数，**没有匹配hidden向量距离**。记录L2、余弦和是否完全相同，解释结果时检查距离差别。同值来源产生与原图完全相同的目标向量也保留、单独汇总，不把它说成实际施加了非零扰动。

如果只有一个有效祖先叶，无法这样同时改变两个祖先且保持u值，本批记录为无法构造，不偷偷改用另一张图或只动无关分支。这是本构造的覆盖限制，不是模型失败。直接父节点数为1的目标仍可能有两个独立叶祖先，所以不会统一排除单父节点。

## 固定首批范围

- 权重：现有旧C0 s42/e143、s1234/e143，身份由已完成能力评估的run_meta及checkpoint哈希固定。
- 数据：已有六档N32/N64/N128 × shallow/deep。每档扫描固定前16图，不补样；这是已使用过的探索集，不称独立最终测试集。
- 每图至多2个目标。先枚举所有有下一轮可算直接子节点的内部节点，不限制数值；在(直接父节点数，图内较低/较高深度)组之间按固定哈希轮转取样，组内同样固定排序。seed=20261115，两个模型结构候选完全相同。
- 所有结构候选及失败原因写selection.jsonl。实际覆盖的原值、深度、父数及各档数量必须报告；有限样本不保证23种数值或所有父数都齐全，缺组不自动补选。
- 不人为匹配“较浅/较深”六档的实际深度分布；按真实depth再分解，不能把所有差异归因节点数。

## 资格与分母

每个结构候选都运行并记录，不因替换效果重新选点。主配对要求原图目标读出四属性正确、三个来源目标读出前三属性与原图正确身份一致、VALUE分别为a/a+1/a+3。源读出不匹配记录为不合格，不换另一个来源凑数。

同一个q必须满足：depth(q)=depth(u)+1，原图注入前q的全部父VALUE正确，且不改动分支第一轮q正确。所有来源分支共用这份q集合。条件只依赖源读出和不改动分支，不依赖干预是否成功。报告结构选中数、来源合格数、合格q数和失败分布。不同seed的合格集合可能不同，不能仅用两者比例比较模型优劣。

**即时读出与下一轮分开。** 把来源向量写入后，u的即时读出应等于来源读出（代码检查）；随后u可能立即重算回原值。这不自动说明替换无效：同一forward内q仍可能受到输入的异值向量影响。不要以“下一轮u仍为原值”过滤案例。

## 下游预期怎样定义

假设原图q=u+v，u=a，v=c。只换u时，异值分支q的预期是(a+delta+c) mod23，**不是整张来源题面的q答案**：改动祖先叶也可能改变来源题里的v，但接收图的v向量并没被换掉。代码独立重算这两个预期并分别记录。

主问题看第一轮：同值换来源有多大影响，异值是否更常使q变成上述特定值。后续逐轮记录u/q数值和四属性、相对不改动分支的新增正确/错误。后续其它父状态也可能变化，因此“仍等于局部预期”仅是轨迹特征，不能独立证明内部算法。

EMPTY/N/A仍计入共同q分母并单列非数值输出；这里q已经通过不改分支可算性检查，不能自动解释为“还没到可算轮次”。不要只对成功读出数字的q重新算百分比。

## 输出与解释

- records.jsonl：每例结构/题面修改、来源即时读出、五分支及完整来源参考的全数值节点四属性轨迹、来源距离、资格及真值。
- selection.jsonl：每图全部结构候选、未选中/不能构造原因。
- summary/coverage.csv：源资格和来源距离；case_curves.csv：逐例逐轮VALUE/四属性读出指标；paired_effects.csv：同值与异值的逐例差异；summary.csv：按权重、数据档、改变量、轮次及父数/深度/原值分解，原始计数与图等权并列；full_reference_curves.csv只用完整来源真值。
- 一图多目标先图内平均，再图等权。各错误幅度对照重复使用同一不改/同值轨迹，不当独立重复样本。

若同值干扰小、异值更常引发特定q错值，支持局部向量携带与数值相关的计算信息；仍不能说整个向量只有VALUE信息。若同值也频繁扰乱，应先解释来源/上下文扰动。整个实验不是纠错训练收益评估。
