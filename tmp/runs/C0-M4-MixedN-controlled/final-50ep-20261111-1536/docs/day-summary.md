## 1. 离散线：B 的“纠错”机制

### 1.1 Parent-corruption 2×2

协议：teacher-state，N=32，256 图，K=4；A′ 为同架构无纠错对照。

关键条件：R only = u 本身正确，父节点 r 被改错。

| 模型 | R only 下 u 的状态（post1） |
|---|---|
| B-M6 s42 | **recomp 935/1024（91.3%）** |
| A′-42 | true 1024/1024 |
| cyhB s42 | recomp 907/1024（88.6%） |
| cyhB s1234 | recomp 1020/1024（99.6%） |
| cyhB s2025 | recomp 1008/1024（98.4%） |

现象：

- B 在“u 本身正确、父节点错”时，仍把 u 改成按错父值重算的值；
- A′ 保持 u 原值，完全忽略父节点；
- own-state 复现 teacher-state；
- 父节点 r 没修好时，u 基本一直跟着错（B-M6：51/51、35/37、39/40）。

解读（未最终定论）：B 更像 **父节点优先重算**，不是“检测到 u 错再改回”。

## 4. 新 MixedN 数据：最终版（controlled）

### 4.1 为什么弃用第一版

第一版 `gen_mixed_n_data.py` 按 bucket + 拓扑池采样，100k 落在 N32 时深度严重偏斜（depth12 13,333、depth4 10,649，depth9–11 几乎为 0，depth1 为 0），无法支撑“可变 N + 深度 12”的泛化结论，已弃用；当时启动的训练已停掉。

### 4.2 最终生成器

`tmp/scripts/gen_mixed_n_controlled.py`：

- `ControlledDepthDAG`：先随机建一条长度恰为 d 的链，再挂剩余节点且不超过 d，保证每张图 max depth 精确等于目标 d；
- N 权重 10% / 20% / 30% / 40%；
- 可行深度：
  - N=8：d=1–2（N=8 只有 2 个内部节点，最大深度只能是 2）；
  - N=16：d=1–10；
  - N=24 / N=32：d=1–12；
- 每个 N×d 格等配额；
- 100k train / 2k val，seed 20261111 / 20261188；
- `max_length=256`（不是 512）。

### 4.3 数据审计（manifest）

| 项 | train | val |
|---|---:|---:|
