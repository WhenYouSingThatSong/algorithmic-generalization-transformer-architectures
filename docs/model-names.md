不再在新展示中用A′、C₀、C₀′、C+、B-M6等另起主名称；旧名称查[历史映射](records/2026-11-18/model-name-aliases.md)。

## C的版本怎么区分

统一写中文训练说明，不新增字母模型名：

- **C（原始）**：未进行本项目新增后训练的可用连续基线。
- **C（保持后训练）**：增加长程保持监督。
- **C（噪声后训练）**：本批在保持设置上加入噪声的后训练版本。
- **C（语义后训练）**：本批在保持设置上加入语义状态扰动的后训练版本。
- **C（前沿污染纠错）**：2026-11-19批次，机器arm仍为correction；在原50k数据的新可算位置引入连续污染，s42/s1234/s2026各50epoch，无第二层过程监督。
- **C（前沿污染＋过程监督UPDATE）**：同批机器arm仍为update；四层模型的第二层提供UPDATE中间监督信号，末层监督计算、对齐和清零；s2026、50epoch。
- **C（多时点局部纠错、第二层更新监督，延长窗口）**。2026 单种子；部分训练批次延长续算，较晚时点按预算确定。已完成 50 个训练周期。[交付](records/2026-11-21/c-multitime-final.md)
- **C（多时点局部纠错、第二层更新监督，正常窗口）**。42、1234、2026 三种子；各 50 个训练周期，全程采用正常求解预算。完成后注错要求该图当时所有节点数值正确。[交付](records/2026-11-21/c-local-update-finals.md)

旧记录中的“过程监督UPDATE”即“第二层更新监督”。普通纠错三份及前沿污染加第二层监督一份均已交付。[旧批权重](records/2026-11-20/c-update-training-handoff.md)

“前沿”指候选时点，不保证改前读出EMPTY。“过程监督UPDATE”明确表示第二层有中间监督，**不表示硬门控**。新方案的late_budget不保证整图已经算对，只有按实际状态分组后才能使用“完成后注错”称呼。

“C”单独出现只能讨论模型家族；有数字比较时必须写版本。自然失败回放若未来执行，称C（自然错误后训练），不能在未运行前当成已有权重。
两次保持小试产生的不同权重不能都只写“C（保持后训练）”：还须标训练批次/配方ID及checkpoint。

## 一份权重的最小身份

正式结果记录：**模型家族 + 训练版本/配方 + 来源 + seed + checkpoint（及SHA）**。示例：

- A（本组，seed42，e86）。
- B（本组，seed42，e92）。
- B（外部复现，seed42，e84）。
- C（原始，本组，seed2026，e143）。
- C（语义后训练，注错小试批次，起点seed2026/e143，final，SHA见来源）。

同名seed不是同权重；C的四个版本来自同一起点时，不能称四种子。训练epoch仅描述相应运行，后训练final不等同基线e143。

## 实验和现象怎么叫

- 当前两个首批任务称 **“C：输入对齐诊断”**、**“A/B：合法重新赋值”**。
- 研究索引E/M/W/T/U/G和旧交接F/W只作任务定位编号，不作模型名。
- 输入对齐报告的三个现象称 **现象①父输入仍错、现象②子输入仍错、现象③所检查数值均对但子输出错**，不再用A/B/C给现象编号。
- 原始数据分支名（如new_warm、u_wrong）是实验操作ID，不是模型名；展示时给中文说明。

## 兼容与执行要求

1. 新的报告和看板用以上展示名称；机器表如保留arm/model_key，旁附名称映射，不能让读者猜。
2. 原始checkpoint、运行目录、JSON/CSV内部ID、历史哈希与旧提交**不批量改名**，防止破坏追溯和运行任务。
3. 旧记录保留，后续引用时转换展示名并携带准确权重身份。早期不同架构不能仅因旧名字以A开头就并入当前A。
4. 先修改新文档和展示层；若未来调整机器schema，另列显式迁移，不影响正在运行的工作树。

## 实验报告用语

| 代码或历史表头 | 正文优先写法 | 读者需要知道的区别 |
|---|---|---|
| VALUE / VARIABLE | 节点数值 / 变量名读出 | 变量名变了指某个定义位置的读出变了。下游是否用错变量要另测。 |
| first4 / graph_first4_all | 节点四字段同时正确 / 整图所有节点四字段全对 | 四字段为语法类型、变量名、运算字段、数值。标明统计定义节点还是所有题面位置。 |
| D / D+16 / H16 | 按图深度给定的标准求解轮数 / 标准轮数之后再跑16轮 / 从起点共跑16轮 | 本批 D 等于最大依赖深度加一。三个口径分别标注起点。 |
| UPDATE / aligned | 第二层预测该位置应更新 / 预测更新与实际数值改动一致 | 即便两者一致，仍需检查是否该改、算得是否正确。各位置实际都经过模型计算。 |
| frontier / middle / completed | 结构上新可算时 / 计算进行中 / 确认整图数值全对后 | 新可算时的连续状态也可能读出数字；给够轮数与观察到完成分别记录。 |
| recovered / stable / propagated | 目标数值首次改回 / 在注明的轮数内保持正确 / 下游出现符合该错值的结果 | 写明错误从何而来、观察窗口及分母。末两轮正确只说明这两轮。 |
| clean / raw | 无人工注错、同起点对照，或“离散评估固定辅助字段”；按实验写全 | 历史离散 raw 指曾回灌辅助字段的评估路径；原始数据文件用“逐图原始记录”。 |
| OOD / reuse | 节点数超训练范围、依赖深度超训练范围等 / 同一题内重复赋值、或修复后供新算式使用 | 写明偏离哪一个训练分布，以及复用的是变量名、状态还是已求出的结果。 |

表题写模型版本、种子、数据来源、图数和观察时点；表头写“节点”或“整图”。示例：“正常窗口后训练 C，种子 2026，128 张验证图，标准求解轮数，3,871/4,096 个节点数值正确，71/128 张图全部数值正确”。详细评估建议见[能力指标与因果对照](records/2026-11-21/evaluation-and-attribution.md)。
