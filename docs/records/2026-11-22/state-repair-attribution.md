# 同题机制比较、计算空间复用与跨任务原型

本批使用已登记权重测量错误怎样发生、传播和恢复。Agent C 在服务器串行执行，Agent B 依据逐题记录复核。本交接优先于旧看板中尚未启动的停止策略任务。运行中的工作树保留到其交付结束。测试时自适应计算方案另行讨论。

## 执行顺序

从 reproduction 同步到空闲工作树。若计算结果和权重在另一份原工作树，以 `DATA` 指向那一份。命令从代码仓库根目录执行。

```bash
DATA=/absolute/path/to/server/repo
python tools/c_hard_graphs/attribution_queue.py --data-root "$DATA" --plan "$DATA/tmp/analysis/c-update-20261119/data/plan.json" --include-prior-mechanisms
```

该命令复用既有产物的身份检查，先完成轨迹变化、更新信号、身份替换、分支传播、三版本取值和新旧下游六项，然后进入下面四个新增阶段。若六项均已交付，可省略 `--include-prior-mechanisms`。每一阶段先小测再正式，支持用同一命令从已写完的逐题记录接续。只跑小测可加 `--smoke-only`。新结果默认在当前代码工作树的 `tmp/analysis/c-attribution-v1/`，可用 `--out` 指定空闲的独立目录。

| 阶段 | 实际操作 | 能回答的问题 |
|---|---|---|
| 1. 同题四条件 | 相同题面、相同变量、相同结构时点。记录干净自由计算；另将目标值换成另一道仅一个源常数不同的匹配题中该位置的值，继续观察八轮 | 原来的值有没有被修回？错误有没有真正到达下游？同一道题上，离散和连续模型的干净代价与恢复收益如何？ |
| 2. 短时屏蔽父值 | 只在紧接的一次前向中，逐层阻断其他位置对父节点定义位置的注意力。对照为正常注意力和屏蔽另一条分支的同深度位置。三种操作在干净、目标被换错两种情况下都做 | 先看它能否影响原本即将完成的正常计算，再看它会不会影响已算对的值或改错后的恢复。如果正常计算也不受影响，不能据此判定模型没有重算。 |
| 3. 恢复的信息来源 | 分别换目标、父节点、两者、祖先、源常数字面量、无关分支，另换父节点及其全部后代。最后一种在原图数值全对时进行，构造保证只有切口处的一条算式与其父值矛盾。原题和修改了常数的新题都从空状态独立求解作参照 | 对照每轮哪些位置跟随旧题或新题，修复首先在哪里发生。单位置题面替换发生在已有状态中，和整道新题从空白求解的输入不同。 |
| 4. 变量名复用 | 每题 46 条定义，逐条匹配两段算术、位置和依赖完全相同的程序。一段每次采用新名字，另一段允许同一名字定义 1、2、4 次。改变连续或交错赋值、取值前的间隔，以及留下 0、4、8 个保存结果供末尾读取 | 最近一次赋值能否被正确使用？已经保存的结果能否保留？逐条件同时报告实际重新赋值距离和同时存活值峰值，两者有相关时按实际值解释。 |

**模型与样本。** 主四格用种子 42 的 A（同架构 A′）、B、C（原始）、C（前沿污染纠错）。另对连续侧种子 42、1234 各自比较原始、前沿污染纠错和多时点局部纠错加第二层更新监督，共八份独立权重。原始和两种后训练的来源哈希须对齐。A、B 为离散数值替换，连续权重为匹配隐藏向量替换，二者注入的语义对应，改变的信息量可以不同。四格首先比较现有权重的行为，因训练历史和实际污染不同，交互差异本身不能单独解释为反馈形式的因果效应。

前三阶段正式样本为题号 352–367，每个生成深度（4、8）16 图，每图预定一个目标，一层直接下游和终点；小测题号 380。常规观察轮数为图最大依赖深度加一。三个固定起点是目标结构上刚可算之前、刚算出之后和常规轮数后再四轮。记录实际起点，分别检查待算条件和已算对条件。最后一个时点如目标正确而其他位置有错，仍属于晚时点，不能称为全图完成。单题和分层小样本优先用计数报告；42 是四格中唯一共用的种子。

## 交付表怎么读

- 每阶段的 `graph-counts.csv` 保留题号和分母，四条件另交 `four-way-common.csv`，两两比较交 `paired.csv`。四个模型在同一事件均合格后，才进入四格的共同分母。未合格行的效果留空。分开报告各模型干净拟合程度、入选比例和共同集占比。
- 直接修复以「实际在目标位置写入预定错值」为分母。特异传播要求干净下游当轮正确，受扰下游恰好算出错父值对应的答案。另报任何数值偏离或未输出数值的损伤。持续恢复使用「曾发生特异传播且还剩至少两轮」为分母，终点要求目标及下游在最后两轮都正确。窗口不足的事件保留。无损伤可能来自及时修复、迟迟没有使用该值等原因。
- 自然轨迹按结构上已该算和还没到计算深度分层，按自然出现的已填错数、尚未给出数值、从正确变错分别计数。在预定目标自然出现「前一轮正确、这一轮数值错误」时，分叉自由轨迹并在另一臂只回放上一轮正确状态，比较下一轮同一下游。这项分析还要报告其他父值是否正确、自然事件图数。整向量回放也可能带入历史信息。
- 短时屏蔽交 `key-comparison.csv`。三臂共用起点，列出正常更新成功、仅屏蔽父值时受损、仅屏蔽无关位置时受损的逐图计数。该干预作用于一个位置，其他位置的值副本、残差通路和先前算出的状态仍可能可用。
- 每张原始轨迹保存起点、供体轮数、实际写入后的读出、父节点／目标／直接下游／终点的逐轮四字段。每阶段交 `delivery.json`，附汇总表哈希。提交小表和有代表性的成功、失败或零覆盖例子到协作文档。逐图原始记录和训练权重留在服务器。
- 依据仓库团队用语规则，把 `fit-sources.json` 的训练及验证材料与当前干净图的节点数值正确率、节点四字段联合正确率并列。不同目标函数的损失不直接横比。某份权重缺少同口径曲线时标明缺项；拟合水平相差较大时保留行为描述，机制归因待比对。

## 两个可以独立运行的原型

**架构对照。** 以下只做端到端小测。四种模型同题同分步监督，使用同一套生成器和输出字段。共享循环、同宽同执行层数的固定深度、参数量最近的窄固定深度、把每轮各定义位置的四个预测字段写入草稿的共享循环分别训练；训练题号为偶数，评估题号为奇数。单个循环块在各阶段复用；固定深度每阶段有独立块。草稿允许后续读到所有已经写下的表。四模型都在相同阶段接受一次匹配供体替换，同时输出实际参数、序列长度、块内乘加估计、损失和受理分母。草稿为逐轮并行写表，与逐词自回归生成有区别。块内乘加估计不包括输出头、反向和访存，参数接近或执行层数相同也不等于耗时相同。默认两步训练仅验收流程，正式拟合所需预算另议。

```bash
python tools/c_hard_graphs/architecture_controls.py --out tmp/analysis/architecture-controls-smoke-01 --device cpu --steps 2
```

**跨任务。** 队列末尾导出十进制逐位进位和模 23 顺序程序的输入、参考轨迹、最终答案与哈希。每套 512 个条件实例，包括相同基础题的配对变体。加法按低位到高位排列，可控链长；程序包含重赋值和延迟读取。另导出同题强制改变一次进位或一次赋值后，继续执行得到的轨迹。这里测的是一个明确的反事实执行；“恢复原题”是另一种目标。原图模型没有直接接收这两种任务输入的适配或训练。以下命令以参考答案做评分器回环，交付时另列真正模型的预测来源。

```bash
python tools/c_hard_graphs/transfer_tasks.py --predictions tmp/analysis/c-attribution-v1/transfer-benchmarks/answers.jsonl --out tmp/analysis/transfer-clean-check.json
python tools/c_hard_graphs/transfer_tasks.py --forced --predictions tmp/analysis/c-attribution-v1/transfer-benchmarks-forced/answers.jsonl --out tmp/analysis/transfer-forced-check.json
```

**复核责任。** C 交上述阶段产物和覆盖数。B 抽取同一道题，核对实际写入、未来八轮下游、干净配对、共同分母，以及全分支替换只有一个方程冲突。若自然错误或屏蔽父值的有效样本为零，零覆盖本身应写入结果。移植到离散 B 的具体训练改动，待本批出现可复验差异后再定。
