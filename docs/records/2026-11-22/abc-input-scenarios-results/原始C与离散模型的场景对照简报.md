# 原始 C 能改写已算对后被篡改的内部值，离散 A′ 与 B 在这一行为上明显分开

## Brief

- **已算过的内部位置被写入错数，原始 C 即使没有专门纠错训练，也能在后续循环中把它算回正确值。** 在四份权重都已算完整图的 79 道共同合格题上，B 和两份 C 在最后两轮均有 79/79 次目标值正确，A′ 为 0/79。B 的修回更快，两份 C 的速度有明显种子差异。
- **已有数值与空位对 A′ 的后续行为有决定性区别。** 在扩展组同样的 64 道已完成题上，将内部值换成另一个数字，A′ 到第 16 轮仍保留错数 64/64；把同一个位置换回空值，下一轮填对 64/64。输入变量是一个例外，标准组整图完成后改输入变量，A′ 有 18/79 次下一轮读回正确值，题面常数始终可见。
- **可以改写已有值，同时意味着正确答案也会因错误的上游输入而被改动。** 已完成图上只改内部值，标准组里 A′ 的直接子节点在 79/79 题上保住答案；B 的直接子节点在 79/79 题上曾算出那个特定错值，末两轮又全部回正。两份 C 分别有 42/79、11/79 题出现这种特定传播，其中末两轮分别恢复 42/42、11/11。
- **B 和 C 有时都没答对，但做的是不同的事。** 在目标正要计算、两个父值被改动且偏差恰好抵消时，B 在下一轮有 52/64 次留空；C 42、C 1234 分别有 53/64、49/64 次给出错误的数字。这些轨迹允许比较状态更新方式，是否显式发现冲突仍需独立证据。

## 同一张已完成的图

标准组图 0，32 节点，最大深度 4。原图给出中间结果 `u = (16 + 9) mod 23 = 2`，直接子节点 `q = (u + 10) mod 23 = 12`。整图首次全部算对后，程序只把 `u` 从 2 改为 12，`q` 仍是正确的 12。此后模型自由运行。每格依次是 `u` 与 `q` 的数值。

| 权重 | 注错后尚未运行 | 续算第 1 轮 | 第 2 轮 | 第 3 轮 | 第 16 轮 |
|---|---|---|---|---|---|
| A′ | 12，12 | 12，12 | 12，12 | 12，12 | 12，12 |
| B | 12，12 | 2，22 | 2，12 | 2，12 | 2，12 |
| 原始 C 42 | 12，12 | 2，22 | 2，12 | 2，12 | 2，12 |
| 原始 C 1234 | 12，12 | 2，3 | 2，16 | 2，12 | 2，12 |

同题的干净分支一直读出 2 和 12。A′ 保留了错误的中间值，也保留了正确的子节点答案。B 和 C 42 的逐轮数值完全相同，修回中间值的同一轮，子节点恰好按注入的 12 算出了 22。C 1234 也回到了正确答案，子节点走过了另外两个错数。仅看最后一轮会漏掉这项差异。

## 两种容易误读的注错结果

**父值坏了，目标即将第一次计算。** 四个模型的目标下一轮都是 0/64 正确。逐题看，A′ 和两份 C 都是 64/64 次精确算出了由错父值推出的答案。B 是 32 次算出该错数、32 次仍为空。把两个父值同时改错、但让偏差抵消后，按实际输入计算的模加和应与原题相同。此时 A′ 首轮 64 次全对，B 是 12 次对、52 次空，C 42 是 11 次对、53 次其他数字，C 1234 是 15 次对、49 次其他数字。连续模型移入两整段向量，变化可能涉及数值之外的信息。

**只动另一条分支。** 在目标将要计算的时点，B 有 26/64 题被汇总为所观察的直接子节点“受损”。回到逐轮值，这 26 次全是在续算第 2 轮比干净分支多空了一轮。16 轮观察中均未出现额外的错误数字。A′ 和两份 C 在相同条件下均为 0/64 额外受损。这组差别体现为出值时机。

## 同题拟合、适用范围与自然错误

标准组 128 节点、深度 4，在标准轮数加四轮时，干净节点数值正确数依次为 A′ 1434/4096、B 1233/4096、C 42 为 4091/4096、C 1234 为 4092/4096。整图完成后改内部节点的 79 张四方共同合格图里，60 张为 32 节点，19 张为 64 节点，128 节点为零。该项四方结论目前限于前两个规模。

对“目标首次算对后改错”，再限定四模型在同题标准轮加四轮时整图数值全对，并且在同一绝对轮次注错，剩 27 张。下一轮回正依次为 **0/27、27/27、26/27、14/27**。在这个同题基础能力和注错时点都对齐的子集上，主要行为差异仍可见。该条件控制了所测题上的表现，四份来源模型完整训练曲线与最终损失的统一比较仍缺。扩展组按实际数值资格计数，C 1234 的 2,688 次场景中有 26 次整图完成后的写入满足数值要求但四字段资格未全满足。

自然轨迹另计。A′、B 在本次定义的机会内，正确节点随后变成另一个数字分别为 0/303,231、0/294,688。两个 C 有 217 和 465 次。经人工回放上一轮正确状态，可使下游从特定错值变回正确值的边分别有 28 和 24 条。在这批边中，原样自由续算且至少留有两轮观察的分别是 27 和 24 条，观察窗内两处曾连续两轮均正确均为零。人工注入单个错值后的恢复，与自然产生错误后的恢复应分别报告。
