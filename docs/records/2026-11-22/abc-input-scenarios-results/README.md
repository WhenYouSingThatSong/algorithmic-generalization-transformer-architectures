### 2.2 改父值、祖先或输入源时，改动是否被继续使用

- 扩展组、目标将要计算前只改直接父值：四模型目标下一轮均 0/64，子节点均 64/64 受损；这是“必须使用当前父值”的阳性场景。
- 扩展组、目标将要计算前只改输入节点已算出的值：A′ 目标 64/64、子节点 0/64 受损；B 64/64、63/64；C（42）64/64、35/64；C（1234）64/64、28/64。A′ 保留了原值、没有把改动传播下去；B/C 的目标读数仍对，但子节点明显使用了下游改动。

## 3. 例外与边界

- 本批是四份/多份固定权重的行为读数；A′、B 的训练历史与 C 不同，不能把差异单独归因于离散/连续反馈或纠错训练。
- 连续 C 的注入是匹配位置的完整 hidden 行，离散 A′/B 只改数值字段；改动的信息量可以不同。扩展组“相消”“一致/冲突”等结果受 hidden 状态影响。
- 报告中的“下一轮正确”是目标读数，不等于下游未受损；下游看 `child_damage` 与 `end_joint` 两列，终点没有子节点。
- C_s1234 的 26 个 strict 4-field 异常均在 `complete` 场景，variable token id 不一致但写入数值正确；最终报告的 expanded 路径按 `value_eligible` 计入这 26 个，若按严格四字段应扣除。明细见 B 侧 `c-only-expanded/full-eligibility-anomalies.csv`。
- 标准组有些场景因四模型实际求解进度不同而不可共同合格；报告只使用共同合格行，空分母留空，不补零。
