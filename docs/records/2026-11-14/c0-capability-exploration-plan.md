# C0 能力与自由运行过程：首批探索

## 目的与范围

先描述当前 C0 在不同规模、深度、计算预算下的基本能力和状态保持情况，再选择 C+ 要解决的错误类型。首批不训练 C+，不注入 hidden 扰动，不启动全量机制矩阵。

模型使用旧 C0 s42、s1234 的现有可用权重，优先沿用看板已报告的 e143，固定实际 checkpoint 路径/哈希；不为本批测试另扫 checkpoint 挑最优。用户已明确 s2025 从训练 loss 可见欠拟合，排除本批评测；保留既有记录，不把它混入本批均值。s2026 完成训练、由执行 agent 确认基础训练正常后，在同一套数据和规则上补入，不等待它才开始 s42/s1234。冷存 C0′ 和 vocab33 不纳入。

首批目标为下列六档，每档约 64 张固定留出图，两个权重使用相同图。这是探索样本量；先看结果再决定是否扩样。

| 节点数 N | 浅层：实际最大依赖深度 ≤6 | 较深：实际最大依赖深度 7–12 |

| 32 | 训练配方附近的能力参考 | 固定规模增加深度 |
| 64 | 浅层规模扩展 | 规模与深度共同变化 |
| 128 | 更大浅图 | 更大较深图 |

- 固定图后再运行；训练/验证/测试已有用途注明，本批用来探索预算和现象，后续独立验证另留数据。
- deep_v2 极深/宽压力池暂列第二阶段；避免先把极深任务全部截断成同一种失败。

## 计算过程与记录

1. 每张图从原始输入出发，按原 C0 nointerm 路径自由续算。每轮回灌 hidden；解码仅用于观察，不能为了“clean”把离散字段写回 hidden。eval 模式，无教师强制状态回灌。
2. 首批每图固定运行 **64 轮**，每轮保留节点前四字段读出和真值；从同一轨迹取 2/4/8/16/32/64 轮切片。64 是探索上限，不是正式最优 H。
3. 使用全部固定样本绘制曲线，不只保留“仍未解完”的图；不逐题取最佳轮次作为正式分数。另列与真实图深度对应的参考完成时刻（按既有 teacher 时间定义换算），用于区分未到计算阶段和计算失败。
4. 记录整图 VALUE 首次全对的时刻 tV，以及节点四属性整图首次全对的时刻 t4，分别统计；t4 不存在时不阻止观察 VALUE 完成后的行为。
5. 对曾完成的图，按完成后的相对轮次观察：第一次数值退化、第一次仅其他字段退化、错误节点数、是否回正、是否反复。注明各相对轮次仍有足够观察长度的图数；尚未完成/完成太晚的图单独列出，不虚构稳定时长。
6. 原始逐节点读出轨迹优先保存。代表性错误的少量 hidden 快照可由执行 agent 按后续分析需要保留，不要求把所有图所有轮完整 hidden 全量落盘。

## 指标与产出

- 核心：节点 VALUE 正确率、节点前四属性同时正确率，分 seed、数据档、轮次报告。节点为叶变量/内部变量/结果节点的定义位置；排除 PAD、题面常数、运算符。
- 分解：全部节点、内部节点、按真实依赖深度的节点表现；结果端 sink 数值正确率单列。逐图等权为主、节点加权为辅，深度层缺失时注明有该层的图数。
- 辅助：整图数值全对率及整图四属性全对率保留，明确不等于节点级指标，不作为唯一能力结论。其他字段错误较多时给出 SYNTAX/VARIABLE/OPERATION 分解，帮助解释两项核心指标的差距。
- 过程：提供逐轮曲线、首次完成比例和时刻、完成后保持/退化曲线；“末尾连续两轮正确”可作窗口内稳定摘要，不等于无限期稳定。全样本能力曲线与“曾完成图”的条件分析分开。
- 示例：选少量从未算对、延迟算对、完成后数值漂移、仅其他字段漂移、漂移后恢复的轨迹，未出现的类型如实注明。解码变量名变化不直接证明连续计算按另一个变量路由。

交付一份简洁总报告：①规模×深度×权重能力表；②逐深度表现；③逐轮与完成后状态曲线；④典型轨迹；⑤现象对 C+ 的启示及尚不能判断之处。主数据和预算固定后再运行，不根据效果临时换题或挑终止轮次。
