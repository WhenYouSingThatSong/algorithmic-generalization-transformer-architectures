# 现有连续纠错模型的难图评测

权重采用正常窗口后训练、第二层有更新位置监督的 C，种子 42、1234，各取第 50 个后训练周期。两份权重分别报告。与六档原始图评测互补，沿用[权重回执](c-local-update-finals.json)和[拟合记录](c-local-update-fit-history.md)。本批只运行现有模型的稠密循环。问题是额外轮数在哪些节点完成计算、在哪些节点引起退化，以及已经读对的状态受扰后下游会怎样。

## 题怎样构造

整道题一次给模型。六个非零且互异的模 23 常数作为叶，每个内部节点做双输入模加法，每个分支沿前一个结果与一个叶值不断相加。按深度排列算式，同层顺序由题号决定。这里的计算宽度指同一依赖深度的加法节点数，叶单列。最大依赖深度指从叶到结果的最长边数。生成器同时保存每层真实宽度、逐节点依赖、token 位置、名字版本和标签。

| 问题 | 固定构造 | 可以怎样比较 |
|---|---|---|
| 简单位置是否过早或过晚停止 | 一条最长链，其余分支长度都是 2 | 同一图分别追踪早完成的末端和最长链末端。看继续整图迭代时各自算对、改坏、回正的时间 |
| 相同工作量如何分配 | 同一宽度、深度、节点数、token 数、叶常数及加法数。一组分支长短悬殊，另一组保留最长链，将其他计算尽量平分 | 按题号配对。比如宽 4 深 8 的两组分别为 [8,6,2,2] 和 [8,4,3,3]。位置排列随拓扑变化，此差异属于构造的一部分 |
| 深且宽时是否还能算 | 所有分支都延伸到最大深度。计算宽度取 4、8，最大依赖深度取 8、15，两轴交叉 | 对同一规模比较时列出节点数。全长分支相对混合分支还增加了工作量。上述图都是规则链束，结果适用于这种拓扑 |
| 变量名反复复用有何影响 | 同一算式程序用三种命名。每次用新名、每条分支每 4 次定义循环用名、每 2 次定义循环用名。右侧取最近一次定义，旧版本最后一次被读过之后才覆写 | 按同一道题、同一个结果位置配对。报告两边都对、仅独立命名对、仅复用对、都错。另记输出碰巧等于某个可区分旧版本答案的次数，此匹配只能作为线索 |
| 能否超出 128 次定义 | 单独加宽 8、深 20、166 次定义、983 token 的全长图，只用两种复用周期 | 词表仅含 128 个变量名。这档检验固定词表里的计算步数扩展，缺独立命名对照，无法单独归因于命名 |

每种子正式运行前四种分支形状 × 四档宽深 × 每档 32 个固定题号，共 512 道三种命名的配对题；另有 32 道超 128 次定义题，两种命名。合计 544 道基础题、1,600 个输入。两个种子完全同题。同一题号跨构造、跨命名、跨时点的结果是配对观测。训练分布外同时可能涉及深度、长度、拓扑与输入顺序，须结合六档原始图的成绩和训练曲线解读。

## 错误怎样注入、怎样认定传播

在 16 个配对档的前 8 题、独立命名输入上，固定选最长链中部的上游节点和紧接的直接下游。分别在上游结构上刚可算的一轮结束、以及标准求解轮数后再运行 4 轮时尝试注错。逐例记录下游此前是否曾读对、干净图当时是否所有值正确。后一个时间点按预算确定，实际完成情况另有字段。

把同一题第一个叶常数改动非零模偏移，在同轮数得到供体向量。只替换上游定义位置。设计保证该上游和直接下游的数学答案都恰好移动同一个偏移。原题上游四字段正确且供体读出预定错值、其余三个字段正确才执行。未通过的尝试保留原因。每个种子 256 次预定尝试，按时点及下游此前是否读对分开。生产轨迹中的“曾读对”仅描述输出。

随后把同一快照复制为两臂，同批跑 8 轮。一臂原样续算，另一臂换入向量。只有同轮干净下游正确、受扰下游恰好读成预测错值，才计一次特异传播。联合持续恢复的分母是出现过该传播的事件，要求受损之后两节点同时恢复，并至少连续正确两轮直至观察结束。另报受理数、上游第一轮修回数、两臂每轮的具体值。整向量干预也改变其他潜在信息，需结合原有同值异来源对照解读。

## 执行与交付

Agent C 已交[原六档评测](c-selected-eval-results.md)。Agent B 负责本批独立目录，可用独立工作树和空闲 GPU；同一模式与种子的输出目录仅一个写入者。仓库根目录运行，计划文件沿用原训练数据目录；独立工作树可用 `--plan`、`--checkpoint` 指向原路径，入口校验哈希。设备用服务器的实际空闲卡映射。以下命令各执行一次。

```bash
python tools/c_hard_graphs/hard_eval.py --model C_s42 --smoke
python tools/c_hard_graphs/hard_eval.py --model C_s1234 --smoke
python tools/c_hard_graphs/report.py --smoke
python tools/c_hard_graphs/hard_eval.py --model C_s42
python tools/c_hard_graphs/hard_eval.py --model C_s1234
python tools/c_hard_graphs/report.py
```

小测每档 1 题，覆盖最长序列和所有干预时点。正式运行复用同身份下已完整写入的单题文件。输出在 `tmp/analysis/c-hard-graphs-v1/{smoke,formal}`，保留身份、完整题面、各位置每轮 VALUE、前三字段联合正确标志、VARIABLE 正确标志和逐次干预。模型文件严格核对回执。报告附运行提交、两份权重身份、时间和产物位置。

验收提交五张正式汇总 CSV，各表按种子分列，保留分子和分母。

1. `capability-summary`。标准求解轮数（最大深度加一），以及再运行 4、8、16 轮的节点数值、节点四字段联合正确、变量名正确、相对标准轮次由错到对／由对到错。给出逐图等权均值；整图全对仅作补充。“末端”分组的全对仅指该组全对。
2. `profile-differences-summary`。相同节点数的两种长度分布，按图配对的正确率差值，方向为长短悬殊减去其余分支均衡。
3. `paired-naming-summary`。同一节点独立命名和复用命名的四格原始计数，顺序与标签已保持一致。
4. `early-readouts-summary`。各节点在其依赖深度加一时读取一次，并与同一条完整稠密轨迹最后一轮比较。另报曾正确、早期正确随后曾丢失、最后仍错误的数量。利用真值回看每个位置是否曾正确只给出事后上限；提前输出或冻结位置可能改变下游，这项测量没有运行提前停止策略，也不能估算实际加速。
5. `propagation-summary`。每一档的计划尝试、接收端不合格、供体不合格、有效注入、特异传播、受损后联合持续恢复。零受损时条件恢复率记为不可估。原始轨迹可单独追查上游已修回而下游仍错误的情况。

这批只建立现有两份权重的行为基线。出现收益或退化时注明对应的难度、轮次、种子和基础拟合。新架构、直接归因于纠错训练、实际节省多少计算，分别需要后续对照。
