## 两个主指标，以及对任务负责的读数

1. **节点数值正确率**。逐图统计结果节点有多少给出了正确数字，再对图平均。最终空白计错。过程另分“父值未备”“已可算仍空”“已有错误数字”“正确”。全节点主表配一列内部计算节点，检查容易的叶节点是否抬高平均。
2. **节点四字段同时正确率**。同一位置的语法类型、变量名、运算字段、数值四项须同时对。与数值率并列；补报“数值对且名字错”的实际交集。结果位置上语法或运算字段可能恒定，避免把四个字段简单平均当作部分得分。
3. 给每图错几个节点的分布、末端输出准确率、整图全对数。前者区分零星失误和整条链崩溃，末端结果衡量任务后果，整图全对衡量完整交付。每个规模单列，预先固定汇总权重。同图配对比较，并以图为单位估计区间；种子分表。需要单个平滑的置信度指标时，可在预定时点补充正确数值的负对数概率，须有 logits 或相应概率记录。
4. **增加循环的净变化**。对同一节点，在两个固定预算间列出“空白变对、数字错变对、对变错”，都除以同一批节点数；其他非数字读出另列以闭合净变化。逐轮曲线同时报实际停在该轮的结果。曾经正确的最优轮次只用于分析可达性。研究可部署停止规则时，结构给出的深度、模型实际可见的信号、看标准答案挑出的轮次须明示。
5. **纠错的收益与代价**。单列实际改坏了原本正确目标的次数；在这些事件上报首轮修回和固定窗口最后两轮正确。单列原本正确的下游第一次被带错的比例、错了几轮、最终输出是否受损。用同题无注错轨迹扣除自发漂移，同图无关位置衡量误改。自然错误、人工注错、未完成的新计算有不同分母；未覆盖的条件记缺失。先按固定候选图报告覆盖和总体任务后果，再给共同合格事件上的条件效果。
6. **可被使用的修复**。在父节点读出恢复后，放一个依赖它、干净对照能算对的新计算。交叉统计“父读出对/错 × 子计算对/错”。需要区分两种候选父值时，选代入后能给出不同模 23 答案的题。第二层更新预测另报应更新位置的召回、健康位置误报、末层实际算对及二者同时正确。读出一个更新计划本身未节省计算。

## 用测试分布检验研究主张

当前主力 C 训练于五万张固定 32 节点、最大深度 6 的模 23 加法图。已有正式协议按节点数及实际最大依赖深度分层（浅 ≤6，深 7–12）。新正式集每层 128 图做基础能力，固定前 32 图做更新分类；历史六档每层 64 图。训练同配置留出图衡量分布内泛化。32 节点深图是深度外推，64/128 节点浅图是规模外推，64/128 节点深图兼有两者。增加运行轮数属于计算预算外推。相同节点数、深度范围仍可能有不同的拓扑、扇入及长度分布。[建集](../../../tools/c_update/prepare.py) · [筛选条件](../../../tools/c_capability/c_common.py)

| 想检验什么 | 配对构造及解释 |
|---|---|
| 多跑一轮能完成更长的依赖吗 | 固定节点数、运算和答案分布，比较长链与多条短链；另固定实际深度加宽图。匹配相同深度值、记录序列长度、叶数及扇入。按依赖层看首次正确的轮次。只增加互不依赖的算式，属于检验额外循环收益应较小的对照。 |
| 错误的后果会放大吗 | 同一题同一时点，分别改无下游的末端和有多个下游的中间值；再测两条路径汇合、多个相邻错值、暂时错误与持续错误。保持节点度数或深度可比。局部修回相同的两个模型可能对最终答案造成很不一样的损伤。 |
| 能否保留已完成的计算并继续使用 | 同一程序配“每次全新变量名”和“旧名最后一次读取后回收”。分别增加计算总数、同时存活的值数、写入到再读取的间隔。看新消费者读到旧值的兼容错误，以及保存下来的旧计算能否继续使用。单独增加定义数不能证明扩展了同时可用的存储。 |
| 能否发现并纠正自己实际用过的错误 | 常规无干预题用于测自然错误率。在匹配题上把错误中间状态交换为另一个语义明确的状态，检验下游是否按预期改变。同值异来源、无注入、等强度噪声为对照。连续状态允许多种正确表示，路径外的一次数值读出只作候选线索。[交换干预方法](https://proceedings.neurips.cc/paper_files/paper/2021/file/4f5c422f4d49a5a807eda27434231040-Paper.pdf) |
| 能否跨任务复现 | 若要主张一般算法推理优势，可再选逐位加法。在相同位数、相近数字分布下改变连续进位长度，另用长但无进位链的题作对照。第二类可考虑可达性传播，正确性由独立求解器给出。新任务需各模型获得同等训练及可用信息；原图权重直接跨词表测试回答另一问题。[算法推理基准 CLRS](https://proceedings.mlr.press/v162/velickovic22a.html) |

主表保持固定部署预算，再画准确率随实际前向次数和计算量变化的曲线。分层预留极易、临界难度、超出能力三段；临界段可用独立开发图校准，再冻结测试样本。对不同训练法报告同一干净和同一受扰任务分布，预先声明扰动率或报告收益随扰动率的变化。人为给每题注错测的是抗扰能力；自然分布上是否常受益还取决于真实错误率。

## 哪些对照允许哪些归因

- 同权重、同图、改变轮数，能估计该模型多用计算的净收益。匹配计算量的非共享层 Transformer 对照，才进一步回答共享循环结构是否带来优势。同时记录训练数据与监督、可见上下文、执行层数、参数量及推理成本；参数匹配与算力匹配可分别报告。[增加递归计算的实验先例](https://proceedings.neurips.cc/paper_files/paper/2021/hash/3501672ebc68a5524629080e3ef60aef-Abstract.html)
- A 和 B 同为循环模型，现有同架构配对显示纠错训练配方与已填错值的修复能力有关。B 能跟随坏父值重算也能修正；若要主张“只在有错时重算”，还需单独识别触发和信息来源。正确位置输出保持原值也可能经过重算。
- 连续模型先比较同种子原始权重、普通纠错、正常窗口局部纠错加过程监督三个现有版本，在同图同预算上同时报告干净代价、实际损伤、下游恢复及使用。原始权重到后训练终点是整套配方的变化。单独识别过程监督作用时，保持污染时点、更新预算、优化器及末层目标一致，显式约定去除第二层监督后依赖它的对齐项如何处理。拆分污染和额外续训的效应，则需等预算普通续训。两类对照回答不同问题，此处只列证据需求。
- 最强也最可证伪的候选主张是：在需要长链计算或修复已被使用的中间值时，同样的额外算力能否带来更多正确的末端输出，同时保住先前正确且无关的结果？若优势只存在于人工注错、只出现在读出恢复、或代价是明显损伤干净求解，就把主张限于对应条件。
