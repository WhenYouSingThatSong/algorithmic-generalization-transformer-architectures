# B、C模型实验简报

整理日期：2026年11月15日。范围：11月14日完成的实验及随后核查；只报告已完成内容。

## 1. 任务和模型

任务是一组有依赖关系的加法方程，所有结果取模23。例如，`u=5，v=u+18`，则`v=0`。输入包含整道题，需要求解的位置起初没有数值。模型反复处理整段输入，每轮同时产生各位置的更新结果。

| 模型 | 本次使用的权重 | 循环时传递什么 | 本次用途 |
|---|---|---|---|
| 无专门纠错训练的离散模型 | 随机种子42，第86个训练周期 | 上一轮解码出的离散字段 | B的对照模型 |
| B：有纠错训练的离散模型 | 随机种子42，第92个训练周期 | 上一轮解码出的离散字段 | 人为改错后，观察传播与恢复 |
| C：连续状态模型，无专门纠错训练 | 随机种子42、1234，均为第143个训练周期 | 上一轮隐藏向量；解码字段只作记录 | 观察求解能力及继续循环后的变化 |

权重对应名称：无纠错离散对照为 **A′：`A-L4D384fast-Nodes32-ADD-L4H16D384-DeBERTa`，s42/e86**；B为 **`B-M6-Nodes32-ADD-L4H16D384-DeBERTa`，s42/e92**；C为 **旧C₀ `C0-M4-Nodes32-ADD-L4H16D384-DeBERTa` 的 `s42_e143`、`s1234_e143`**，取自续训至150周期的运行。这里的e表示权重保存的训练周期；完整文件路径及哈希见文末原报告。

三类模型均采用4层、16个注意力头、隐藏维度384的循环Transformer。C使用的是原32节点、依赖深度不超过6的训练版本；本次未使用另一套混合节点数训练版本。C的第143周期权重是固定比较对象，不是按本次测试结果选择的最优权重。

离散字段指模型明确读出的变量名、数值等符号；隐藏向量指模型内部的一组连续数值。C把后者直接传给下一轮，不把读出的名字和数值重新作为输入。

## 2. B：人为改错后会发生什么

### 实验操作与主要结果

主实验使用256张32节点图，两模型使用相同题目。每次干预均配一条同模型、同起点、不改任何值的对照轨迹。除持续改错实验外，只在开始时改一次，随后让模型自由运行。只改数值，不改变量名、表达式或题面常数。

256张图均达到两模型共同完成条件；其中218张选出365条用于中间节点及父节点实验的目标链。因此，下表的365是干预目标数，不是图数。

“节点的父节点”指它计算时直接引用的变量；“下游”指直接或间接依赖它的节点。

| 实验 | 具体怎么做 | 样本与观察长度 | 结果 |
|---|---|---|---|
| 节点尚未算出时改错 | 在该节点下一轮应被算出的时刻，分别向空数值槽填入错值、改错一个父值、同时做两者，并保留不改值的对照 | 365个目标，继续16轮 | 仅向空槽填错值时，B首轮输出没有留下可观察错误；改父值及同时改两处时，B曾受损节点到最后两轮全部正确。无纠错训练对照的受损节点没有恢复 |
| 节点刚算对时改错 | 节点刚得到正确值后，分别改它、改一个父节点、同时改两处；其余位置不变。目标值加1，父值加3，均取模23 | 365个目标，继续16轮 | 单独改目标或父节点时，B均在首轮把直接改动点修回，分别365/365；下游仍可能暂时出错。各条件中曾受损节点到最后两轮全部正确；无纠错训练对照没有恢复 |
| 整张图算对后改错 | 在两模型首次共同达到整图数值全对时，分别改中间节点、选定的父节点、由题面常数确定的起始变量、没有下游的末端节点，或另一条分支的节点 | 中间/父节点/另一分支各365个目标；起始变量和末端各512个；继续16轮 | B的直接改动点在五类实验中均首轮修回。改中间节点后，曾受损节点中2262/2263在最后两轮正确，仍有一个下游节点未恢复。其余有输出损伤的条件均恢复；无纠错训练对照的受损节点没有恢复 |
| 长时间继续运行 | 对预先固定的32张图，重复上述部分干预，延长观察到64轮 | 中间节点等49个目标，起始变量/末端各64个 | B部分节点先恢复、又出错，但这些反复都发生在第16轮前；所检查节点在第17–64轮没有再次出错。该子集不包含上面的未恢复案例 |
| 连续多轮改错一个父节点 | 整图算对后，每轮前向前都把同一父值强制改错，连续4轮，再停止人为修改 | 早期小规模试验：32张图中选出42个目标，释放后观察64轮 | B的322个受损节点事件最终全部恢复，无纠错训练对照的39个受损事件未恢复；这是小规模结果，尚未扩大到主实验样本 |
| 更换起跑状态 | 在固定子集上，比较从模型自己算出的中间状态出发，与从程序构造的正确中间状态出发；干预位置、时点和数值相同 | 64张图、92个目标；两模型、两个时点、四种条件 | 交集中1472条轨迹逐轮一致，包含不改值的对照 |
| 核对训练时实际改了什么 | 抽取训练数据，记录纠错训练选择的位置及替换前后的值，重复采样替换操作 | 256个训练批次、2048张图；每批重复100次抽样 | 161,725次实际替换之前均为空值，没有发现把已有数值改错的操作。说明在这批审计样本中，训练操作与测试中的“算对后改错”不同 |

**计数说明：**“受损”指某节点在不改值的对照中正确，但干预后至少一次输出错误；“最后两轮正确”仅描述观察窗口末尾，不保证永久稳定。同一节点出现在不同干预中分别计数。两个模型的受损集合不同，不能只比较恢复率而忽略分母。B对末端节点512次注错均首轮修回，没有观察到错误输出，因此不能另写成“512个错误输出后来恢复”。

### 三个具体行为

以下均发生在整图已经算对以后。

1. **错误与修正都能沿依赖链传播。** 某图中`u=5，v=u+18=0，w=v+5=5`。把u改成6后，各轮输出依次是：`(5,1,5) → (5,0,6) → (5,0,5)`。u先修好，v和w先后受到错误影响，随后恢复。
2. **父值恢复，不保证子节点恢复。** 同一次干预的另一分支中，某父节点短暂输出空值，子节点从正确的2变成8。第3–16轮，其三个父输入都已正确，分别为10、5、10；正确和应为2，但它持续输出8。这个案例不能用“上游一直错误”解释，也不能据此判断第16轮以后是否恢复。
3. **影响可能超出题目的依赖关系。** 四张图共12个受损节点，没有从注入点到它们的依赖路径。一个例子中，节点的父输入4、15、21都正确，应输出17，却输出0；随后它的下游又跟着0计算，最后逐轮恢复。这12个节点事件最晚第6轮回正。已核对完整图结构，但尚未定位模型内部为何产生这种影响。

这些结果支持B具有修复已有错误的能力，但不能把它概括成“每轮都可靠地按父值重算”。本轮主要结果仅来自一组随机种子的模型对照。

## 3. C：正常求解后继续运行，会发生什么

### 实验操作

两个权重使用完全相同的384张图：32、64、128节点，各分较浅和较深两档，每档64张。不人为改错，也不在算对后停止；每张图从未求解状态连续运行64轮，记录每个数值节点的预测数值、变量名、语法类型和运算类型。

实际最大依赖深度：32节点较浅档为4–6，64/128节点较浅档均为6；较深档分别为7–11、7–12、9–12。因此各规模并非严格匹配深度，不能把档位差异全部归因于节点数。

### 节点正确率

每格为“数值正确率 / 四个属性同时正确率”。分母均为数值节点，包含起始、中间和末端变量，不包含题面常数及填充位置。同一档各图节点数相同，节点汇总与逐图等权平均一致。第16轮和64轮是观察截面，不是按结果选择的停止规则。

| 数据档 | 种子42：第16轮 | 种子42：第64轮 | 种子1234：第16轮 | 种子1234：第64轮 |
|---|---:|---:|---:|---:|
| 32节点，较浅 | 100.00% / 99.61% | 96.83% / 9.86% | 99.85% / 96.09% | 93.26% / 9.33% |
| 32节点，较深 | 99.17% / 98.63% | 93.75% / 9.42% | 99.95% / 95.21% | 90.92% / 8.15% |
| 64节点，较浅 | 99.95% / 99.61% | 90.82% / 8.06% | 99.73% / 96.56% | 84.57% / 9.01% |
| 64节点，较深 | 99.88% / 99.54% | 90.94% / 7.67% | 98.88% / 96.24% | 83.40% / 8.57% |
| 128节点，较浅 | 99.65% / 99.39% | 89.25% / 8.04% | 99.30% / 96.75% | 70.29% / 8.04% |
| 128节点，较深 | 99.93% / 99.78% | 81.93% / 7.24% | 98.32% / 95.98% | 64.25% / 6.71% |

在全部正式轨迹的数值节点上，语法类型和运算类型未出现错误；四属性正确率低于数值正确率，来自变量名错误。64轮明显长于训练时的循环长度，后期结果主要反映额外循环下的保持能力，不能替代正常求解阶段的评价。

### 完成、退化与恢复

两个权重合计768个“模型×图”轨迹中，690个曾达到整图数值全对。其中197个从首次完成到观察结束一直保持全对，493个后来再次出现数值错误；这493个中，只有3个在最后两轮恢复到整图数值全对。这里统计的是整图恢复，不是局部节点恢复次数。

具体例子：

- **数值保持，变量名改变。** 种子42的一张32节点图，第7轮全部正确；第20轮首次出现变量名错误，到第64轮只有3/32个变量名正确，但32/32个数值从第7轮起始终正确。某位置的读出从`x_26=1`变成`x_71=1`，后来又变成其它名字，值一直为1。
- **几乎算完，但始终差一个节点。** 种子1234的一张128节点深图，第14–22轮有127/128个数值正确，却从未整图全对；第64轮只剩95/128正确。“整图失败”在这里不等于大部分节点都不会计算。
- **出现数值错误后自然恢复。** 种子1234的一张32节点深图，第12–48轮整图数值全对，第49–54轮出现错误，第55–64轮重新全对；但第64轮只有4/32个变量名正确。数值恢复与属性全部恢复是不同结果。

493个后来数值退化的轨迹中，变量名新错误先出现479次、同轮1次、数值先退化13次。这个先后关系尚不能证明变量名变化导致数值错误；连续模型传给下一轮的是隐藏向量，错误的解码名字没有被直接写回输入。

## 4. 当前证据范围

- B已做人工改错及逐轮恢复观察；C本轮仅观察自然求解、继续循环后的退化和自然恢复，两者不能直接比较成“谁更会纠错”。
- C本轮没有训练加入纠错机制的新模型，没有人工向量干预，也没有保存隐藏向量快照；保存的是逐轮属性读出。
- 本轮尚不能确定B或C内部使用了哪种错误检测/修复算法。正确率、传播轨迹与恢复现象是已有证据，具体内部原因仍需进一步实验。
