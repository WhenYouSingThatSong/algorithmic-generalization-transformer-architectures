# B / C 实验简报

日期：2026-11-15。范围：最近一批 B 主实验及修复后核查、C₀ 六档自由续算；不混用早期被替代的结果。以下是固定权重上的观察，不代表所有种子或完整内部机制。

## 1. 使用什么权重

| 实验线 | 权重 | 架构与训练设置 | 本批用途 |
|---|---|---|---|
| 离散对照 A′ | seed42，epoch86 | L4H16D384，fast，无专门纠错训练 | 与B配对，判断纠错训练带来的行为差异 |
| 离散 B-M6 | seed42，epoch92 | 同架构、同fast，有原论文的last腐蚀训练 | 研究已有答案的更新、错误传播与恢复 |
| 连续 C₀ | seed42、seed1234，均epoch143 | L4H16D384，M4/nointerm；hidden直接回灌，无专门纠错训练 | 测基础能力和长循环漂移，为C⁺设计提供依据 |

C₀是**旧N32、深度≤6训练分布**的150epoch训练线，固定取e143；不是新MixedN的C₀′，也不是已废弃的vocab33版本。本批未测s2025，未纳入s2026。C⁺尚未训练。

## 2. B：做了什么实验

任务为模23加法图。主批固定256张N32候选图，两模型均完成；其中218张有合格链，共365条。每次注错均配同模型、同起点、不注错的clean轨迹；离散回灌固定辅助字段。

| 实验 | 干预与观察 | 已完成范围 |
|---|---|---|
| early 2×2 | U尚未算出／U刚算对时，分别不改、只改U、只改父R、同时改U和R | 自由运行起点为主；256图候选、365链；注错后观察16轮 |
| 起点对照 | teacher状态与模型自身状态起跑，比较同图同链轨迹 | 64图候选、92链；含clean共1,472条配对轨迹一致 |
| 整图完成后注错 | 整图首次共同VALUE全对后，分别改内部U、父R、叶变量值、结果端sink、无关分支节点 | 内部/父/无关各365次；叶/sink各512次；观察16轮 |
| 长窗口 | 对固定子集延长观察，检查恢复后再错 | 32图候选、49链；64轮 |
| 持续错父pilot | 整图完成后，固定父值错误4轮，释放后观察64轮 | 早期独立pilot：32图候选、42目标；不是主批全量实验 |
| 训练腐蚀审计 | 查看实际训练腐蚀前的字段值 | 256 batch、2,048图，100次腐蚀采样；候选和实际被替换位置的原值均为EMPTY |

**术语：**U为目标节点，R为其父节点。“整图完成”是首次达到VALUE全对，不等于已验证长期稳定。训练腐蚀样本支持EMPTY→值，不能将测试中的“已有正确数值→错值”说成训练时同样见过。

### 主要结果

恢复指标：在观察窗口中曾出现“clean正确、干预输出错误”的节点事件里，最后连续两轮正确的比例。主结果逐图等权；下表括号中的分子/分母是节点事件计数。同一节点在不同干预下分别计数；两模型受损集合不同，不能把恢复率差直接解释成同分母的效应量。

| 条件 | A′ | B |
|---|---|---|
| early的有受损条件 | 16轮末恢复率均为0 | 8轮末逐图恢复率97.94%–99.53%；16轮末均100% |
| 整图完成后改父R | 0/332恢复 | 2,604/2,604恢复 |
| 整图完成后改内部U | 0/365恢复 | 2,262/2,263恢复；逐图等权99.94% |
| 整图完成后改叶变量值 | 0/400恢复 | 6,667/6,667恢复 |
| 整图完成后改sink | 首轮0/512改回 | 首轮512/512改回；输出未出现损伤，条件恢复率记NA |

B的early空槽U写入条件也没有输出损伤，不能写成“恢复率100%”。持续错父pilot中，B释放后H16末322/322受损节点事件恢复；A′对应受损事件未恢复。

### 已观察到的现象

1. **B会更新已有答案，错误与修正能沿依赖链逐轮传播。** A′在本批更倾向保留已有数值。B的长窗口子集中曾出现“回正→再错”，但第17–64轮未再观察到复错；不外推永久稳定。
2. **B不是可靠的逐轮父值重算器。** graph142中，改U：5→6后，下游节点128变成8；从第3轮起其父输入已恢复为10、5、10，正确结果应为2，但它保持8到第16轮。该图不在64轮子集中，之后未知。
3. **影响可以超出任务依赖图。** 无关分支实验中，protected_exclusive区域有12/2,512个节点事件受损，来自4图；原数据依赖核查确认这12个节点都不在注入点下游。部分异常起点父输入正确却输出错误，随后错误沿自身下游传播；12个事件最晚第6轮回正。尚未定位内部原因。

## 4. 当前能说到哪里

- **B：**在这对同架构权重、本批干预下，B表现出明显恢复行为；但并非所有节点都会可靠重算或恢复，且存在依赖图外影响。仍不能确定是持续重算、选择性更新还是多种机制并存。
- **C₀：**本批较短轮数的节点数值能力较好；主要新问题是长循环下的保持与恢复。64轮远超训练循环长度，不能把末轮退化直接当作通常求解预算下的准确率。VARIABLE读出漂移与数值退化须分开研究。
- C各档深度未严格匹配：N32浅为4–6，N64/N128浅均为6，N128深为9–12；不能把跨档差异全部归因节点数。C包未保存hidden，向量干预仍需运行相应案例。
- **尚未完成：**B主批持续错父、改题面D1/D2/D3及跨seed复现；C的因果干预与C⁺训练。局部自洽实验仍暂缓。
