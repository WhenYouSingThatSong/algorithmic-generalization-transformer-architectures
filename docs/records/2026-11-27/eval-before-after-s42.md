## 3. 逐家族的读法

### A′：单调改善，从 99.10% 到 100%

`graph_all` 0.9910（e86）→ 0.9995（e133）→ 1.0000（e188）。三份权重都是"只要数值对，四字段就都对"（strict 与 graph_all 相等），说明 A′ 的位置/名字/运算字段是稳的，失分全在数值。

**这是本轮唯一一个能干净读出"续训变好"的家族。**

### B：训练前就已经满分，这个判据没有分辨力

三份权重 `graph_all` 与 `strict` 全部 1.0000。B 在 e92 就已经把 N128/depth7–18 全部做对，所以**这条评测无法反映 B 续训前后的差别**。要比较 B，必须换更难的判据（见 §5）。

### C：数值大幅提升，但 strict 反而归零——这是指标结构造成的，不是退化

`graph_all`：0.8565 → **0.9485**（+9.2 个百分点，2000 题里 1713 → 1897 题全对）。**数值层面是明确改善。**

但 `strict` 从 0.0140 掉到 0.0000。逐字段准确率给出了原因：

| 字段 | C e143（前） | C e177（后） |
|---|---:|---:|
| SYNTAX | 1.0000 | 1.0000 |
| VARIABLE | **0.9985** | **0.9820** |
| OPERATION | 1.0000 | 1.0000 |
| VALUE | **0.9665** | **0.9910** |

C 续训后 **VALUE 升（0.9665→0.9910）、VARIABLE 降（0.9985→0.9820）**。

而 `strict` 要求**每个节点的四个字段全对才算对，且整图所有节点都要对**。按上表，C e177 的单节点四字段全对率约为 `1.0×0.982×1.0×0.991 ≈ 0.973`；一道 128 节点的图，即使按独立估算，整图全对概率也只有 `0.973^128 ≈ 3%`，再叠加节点间误差的相关性，2000 题里实测为 0 并不奇怪。

**所以 strict 在这里是"乘性放大"的指标，对 C 这种字段准确率还没到 1.0 的模型近乎恒零，不能用来判优劣。** 报告 C 应以 `final_value_graph_all_acc`（数值口径）为主，strict 只作诊断。

## 4. 必须注明的边界

1. **天花板效应**：8 个数字里有 5 个 ≥ 0.9995。A′/B 在这个分布上已接近做满，**"干净求解"对 A′/B 的分辨力只剩 0.1–0.9 个百分点**。
2. **C 的指标不能与 A′/B 横比**：损失口径、回灌内容、strict 的敏感度都不同。只能各自家族内看前后。
3. **strict 指标不适合跨家族比较**（见 §3 的乘性结构）。
4. 本次只用了 N128 这一档。论文 fig4 的 16 档（N=8…128）与 `deep_v2` 压力集本次未跑；抽查显示 `deep_v2` 上 A′ e188 四池全 1.0，同样饱和。

## 5. 结论与下一步

- **A′：续训到 200 周期确实改善了干净 OOD 求解**（0.9910 → 1.0000，且在 150 时已到 0.9995）。
- **B：无变化，已满分。**
- **C：数值显著改善（0.8565 → 0.9485），但 VARIABLE 字段略降；综合严格指标为 0 属指标结构问题。**

因此 PLAN-009 §2 的后两类判据——**已算结果的保持与改写**、**错误传播与持续恢复**——才是能区分 B（以及 A′ 前后）的地方。它们对应本项目已有的 072/073/074 那套扰动/恢复协议，而不是本文件的干净求解评测。
