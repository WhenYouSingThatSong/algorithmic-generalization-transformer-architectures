# 探针与关闭信道：结果

- 日期：2026-11-28
- 设计与依据：[probe-and-channel-shutdown-design.md](probe-and-channel-shutdown-design.md)
- 实现：[tools/c_channel_probe/probe.py](../../../tools/c_channel_probe/probe.py)
- 原始输出：`tmp/analysis/channel-probe/probe.json`

## 1. 运行设置

- 权重：旧 C0 e143，三个种子（s42 / s1234 / s2026）。
- 数据：`N128-heldout-ADD` 前 200 题，每题 128 个结果位置，共 **25,600 个位置**。
- 图解析校验：三个种子均 **0 个标签复现失败**（按“父值之和 mod 23”重算，与标签逐节点吻合）。
- 探针样本：约 2.7 万条（按题切半训练 / 验证）。

## 2. 基线

| 种子 | node_acc | graph_all |
|---|---:|---:|
| 42 | 0.994297 | 0.900 |
| 1234 | 0.977148 | 0.345 |
| 2026 | 0.999883 | 0.985 |

同一个池子里的三个种子差异很大（整图全对率 0.35 到 0.985），这与既有记录里“C 的种子间随机性较强”一致。

## 3. 探针（Q1 / H1）

| 种子 | val acc | **train acc** | 打乱标签 | 多数类 |
|---|---:|---:|---:|---:|
| 42 | 0.0403 | **0.2122** | 0.0441 | 0.0428 |
| 1234 | 0.0454 | **0.2213** | 0.0414 | 0.0402 |
| 2026 | 0.0434 | **0.1858** | 0.0446 | 0.0451 |

23 类的随机水平是 0.0435。

按 lead 分组（lead = depth − t）在三份权重上都**没有趋势**：lead=1 时分别是 0.037 / 0.044 / 0.043，与 lead=5、10 基本持平。

**读数**：验证集上等于随机，但**训练集上也只有 0.19–0.22**。这说明探针**在训练集上就没拟合住**，属于欠拟合，而不是“训练能拟合、验证不行”。

因此本轮**不能**得出“隐藏态里没有该信息”的结论，只能得出：

> 以 384 维线性探针、本数据规模与这个标准化/正则设置，未能从“尚未到轮次”的隐藏态中解出该节点的真值；连训练集都无法拟合。

这与设计文档 §7 局限第 5 条相符（线性探针会低估非线性编码）。要判定 H1，下一步应改用非线性探针（如两层 MLP）并复核训练集是否拟合。

## 4. 关闭信道：冻结未到轮次的位置（H3）

三种变体里**只保留冻结这一种**。另外两种（把载体换回 token 的两种写法）已撤回：
`rewrite` 写回的内容大多是 EMPTY、模型面对“VARIABLE 加已填值”的输入仍输出 EMPTY，
它并没有构成一个离散通道，与 `reembed` 实质是同一件事；两者又都是分布外干预。
把它们与冻结并列只会让人误读成“移除通道 ⇒ 模型不会算”是个对照结论。
原始数字仍留在 `tmp/analysis/channel-probe/probe.json`，不作为结论使用。

**冻结的定义**：每轮前向之后，把「`depth > t` 的结果位置」的隐藏态退回上一轮的值，
其余位置（含 `depth ≤ t` 的结果位置、叶子的常数、`=` 与分隔符，它们的 depth 为 −1）照常更新。

| 种子 | 基线 node_acc | 冻结后 node_acc | 冻结后 graph_all |
|---|---:|---:|---:|
| 42 | 0.994297 | 0.501328 | 0 |
| 1234 | 0.977148 | 0.778438 | 0 |
| 2026 | 0.999883 | 0.380781 | 0 |

**读数**：三个种子的 node_acc 都显著下降（0.98–1.00 → 0.38–0.78），整图全对率全部归零；
但预测分布仍正常（23 种值都有，不是输出 EMPTY），说明模型还在算，只是算错很多。
**未到轮次那些位置的更新承担了实质工作**，但冻结后模型仍能解出相当一部分节点。

**限制**：这是分布外干预（权重是在连续回灌下训练的），只能说明“依赖”，不能量化贡献；
三个种子的退化幅度差异很大（0.38 到 0.78），只能逐种子报告。

## 5. 本轮的结论边界

1. **H2 有支持**：切断跨轮载体后模型基本不计算（输出 EMPTY），整图全对率为 0。
2. **H3 有部分支持**：冻结未到轮次的位置后大幅退化，但未崩溃。
3. **H1 未判定**：线性探针在训练集上就欠拟合，不能作为“不存在”的证据；父值改动控制也因此无效。
4. **rewrite 变体无效**，不能作 A/B 对照；需要重新设计或放弃。
5. 三个种子的基线差异很大（整图全对率 0.345–0.985），任何跨条件比较都应**逐种子报告**，不要只报均值。

## 6. 下一步（待研究者定）

1. **换非线性探针**（两层 MLP）重跑 H1，并检查训练集能否拟合；这是判定 H1 的前置。
2. **修正或放弃 rewrite 变体**：若要模拟离散通道，需明确的输入构造与相应权重，否则不要用它下结论。
3. **父值改动控制这轮无效**。已跑出读数，每种子 n≈50：预测等于改动后新值的比例为 0.061 / 0.020 / 0.060，等于原值的比例为 0.020 / 0.120 / 0.040。两组都接近 0。**原因不是“信息不跟随输入”，而是探针本身就在随机水平（见 §3）**，因此这个控制在当前探针下无法判别任何东西。等换成非线性探针后再做。
