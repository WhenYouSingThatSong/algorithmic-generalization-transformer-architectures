# 跨轮信道这条线：讨论过程（原始记录）

- 整理时间：2026-11-28
- 这是记录文件，不是主文档；主文档对应条目是 EXPERIMENT-075。
- 结论性文件另见：[现状](channel-investigation-status.md)、[冻结与更新幅度](freeze-and-update-magnitude.md)、[度量与消融阶梯设计](vector-difference-and-freeze-ablation-design.md)。
- 本文保留**被撤回的做法、出过的判断错误、以及未解决的点**。

## 1. 研究者的判断（2026-11-27）

离散与连续循环模型最本质的差别在**跨轮的信息通道**：离散侧每轮重新嵌入 token，轮与轮之间只传递已写回的离散字段；连续侧每轮每位置接收上一轮的完整向量，而监督只约束读出、不约束隐藏向量。因此机制的落脚点应在"隐藏向量在监督触及不到的地方形成了什么机制"，且这种机制因缺少监督而有较大随机性，需要多种子与充分训练才看得出。

同轮提出：做一个"不允许未到轮次的向量更新"的小验证，看性能是否退化。

## 2. 实现前的代码核实（2026-11-28）

- `model.py:476` 的 `value_avail_pos = (depth ≤ 目标)`：只在这些位置把 VALUE 换成标签，其余保留输入的 EMPTY。
- `model.py:893`：C 每轮 `label = batch_ext[loop + 1]`，即"depth ≤ loop 填真值"。
- 该轮损失对展平整序列求 CE，无位置掩码。
- 结论：**两个家族的监督结构相同**（可算处读真值、未到轮次读 EMPTY）；差别在跨轮载体与带宽。

这条事实修正了研究者的初始表述（"监督非常不充分"），改为"监督只约束读出、不约束隐藏向量；且要求未到轮次处输出 EMPTY，等于要求模型把已知内容收进隐藏态"。研究者认可。

## 3. PLAN-010 建立（2026-11-28）

第一步两件事：D 多种子从头训练（普通纠错 + 多时间点纠错）；在现有 C 上做小验证与初步机制分析。训练预算：3 个种子（沿用原三个）、200 周期、每 50 周期保留 `last` 与该阶段验证最好的三份；先 4 个 run 并行。

## 4. 关闭信道的第一版与撤回

先做了两个变体：`reembed`（每轮重新嵌入原始输入）与 `rewrite`（把解码值写回 token 再嵌入）。

研究者指出这两个在当前情形下会混淆视听，要求只保留冻结。核实后同意并撤回，理由比"混淆"更硬：

- `rewrite` 写回的内容大多是 EMPTY，模型面对"VARIABLE + 已填值"的输入仍输出 EMPTY，**它没有构成离散通道**，与 `reembed` 实质同一件事；
- 两者都是分布外干预，不能与 A/B 的条件相比。

（另有一条以隐藏态可解码性为切入的做法，研究者要求先移除；本线不涉及。）

## 5. 冻结 + 更新幅度（研究者提出的扩展）

研究者要求：① 记录里只保留冻结；② 冻结再加"允许提前 g 轮"的扫描；③ 用 `1 − cos` 表示每轮更新幅度，在小规模（整张图都算）上按轮次与位置看。

第一版出过一个混杂：按 `lead = depth − t` 的边缘趋势显示"lead 越大变化越大"，但大 lead 只可能出现在早期轮次。加入（轮次 × lead）交叉表后，边缘趋势被证伪：**同一轮次内，未到轮次的位置几乎不动（`1−cos` 约 0.001），只有本轮该算的位置有明显变化（约 0.09）。**

随后研究者要求更新幅度在**不冻结与各冻结条件**下都测，于是把条件参数化（none / freeze0…freeze4）。

## 6. 一个解释不了的矛盾

- 更新幅度显示第 0 轮之后状态就停住；
- 冻结扫描却显示要允许 g=4 才接近基线（g=1 只从 0.517 回到 0.643）。

当时的猜想是"注意力跨位置污染"：被钉住的深节点会成为其他位置的输入。**该猜想未验证**，已在记录中标注。

## 7. 研究者指出关键细节，改变了整个解读（2026-11-28）

> 正常运行时，距计算时点还很远的节点，最大的变化发生在第一次前向。此后到正式求值之前，它们平均每轮的向量变化小得多。这个是不是也值得消融一下，如果第一轮不冻结呢对比。

这条直接指出：旧冻结把位置钉在 `h_0`，**阻断的是第 0 轮那次大变换**，而不是"后续预计算"。于是补了冻结阶梯。

**解读**：`hold_unreached_from0` 的损害全部来自第 0 轮那次变换；第 1 轮之后的逐轮更新对最终结果没有可测作用；算完那次更新基本不必要；多给轮次没有帮助。**§6 的污染猜想因此不再需要。** 另外，早先被列为“未做”的“只允许 `depth ≤ t` 更新、其余保持第 1 轮状态”，其实就是 `hold_unreached_from1`，已在本批做过。

## 9. 研究者同时提出的度量与消融扩展

- 向量差异要覆盖方向、模长、以及两者合起来的量 → 实为五栏并做正交分解（`rel_l2² = radial² + tangential²`，逐条自检）。
- "算完不给更新"是否也值得消融 → 已作为 E / F1 / F2 三个条件执行。
