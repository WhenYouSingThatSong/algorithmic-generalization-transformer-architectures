## 1. 一个改变解读的实测事实

正常运行（不冻结）时，按 `lead = depth − t` 分组，未到轮次位置的每轮变化：

| 轮次 | 未到轮次位置的 `1−cos` |
|---|---|
| t = 0（第一次前向） | **约 0.40** |
| t ≥ 1 | 0.0004–0.011 |

也就是说：**离计算时点还很远的节点，绝大部分变化发生在第一次前向；此后到正式求值之前，每轮变化小两个数量级。**

### 1.1 这对现有冻结结果的解读意味着什么

现有冻结实现是在**每一轮之后**把「`depth > t`」的位置退回上一轮的值。由于第 0 轮就退回了 `h_0`，这些位置在整段运行里一直停在 `h_0`，即**原始 token 嵌入**。

于是现有的冻结实际测的是：**"第 0 轮那次变换没有发生"** 会损失多少精度，而不是"缺少后续逐轮预计算"会损失多少。

因此**"第 0 轮不冻结"的对照是必要条件，不是补充**：只有先让所有位置完成那次大变换、再钉住，才能把问题定位到"之后的微小更新是否有用"。

## 2. 冻结消融阶梯

统一参数化（三者独立）：

- `pre_grace`：非 None 时，每轮之后把 `depth > t + pre_grace` 的位置退回上一轮；0 即现有冻结。
- `post_grace`：非 None 时，每轮之后把 `depth < t − post_grace` 的位置退回上一轮（**已算出节点不再更新**）。
- `start`：从第几轮起才施加上述冻结（`start=1` 即"第 0 轮不冻结"）。

| 编号 | 配置 | 检验的问题 |
|---|---|---|
| A | 都不冻结 | 基线 |
| B | `pre_grace=0, start=0` | 现有冻结（阻断第 0 轮变换 + 后续更新） |
| C | `pre_grace=0, start=1` | 只阻断后续更新，保留第 0 轮变换 |
| D | `pre_grace=0, start=2,3` | 钉得更晚是否更接近基线 |
| E | `post_grace=0` | **算完立刻不许更新** |
| F | `post_grace=1,2` | 算完后允许 1–2 轮更新再钉住 |
| G | `pre_grace=0, start=1` + 更大总轮次 L | 若加大 L 能救回，说明是"算得不够久"而非"缺预计算" |

**判读**：C 与 B 的差距 = 第 0 轮那次变换的贡献；C 与 A 的差距 = 后续逐轮更新的贡献。只有后者才是原假设里"轮次之间的预计算"。

## 3. 向量差异怎么衡量（把方向与模长都覆盖）

现有的两个量：`1 − cos`（只看方向）、`rel_norm = ‖Δ‖/‖h_t‖`（含两者的总量）。

改为四栏，并做正交分解。记 `Δ = h_{t+1} − h_t`，`ĥ = h_t/‖h_t‖`：

| 量 | 定义 | 含义 |
|---|---|---|
| `one_minus_cos` | `1 − cos(h_t, h_{t+1})` | **方向**变化，尺度无关 |
| `norm_ratio` | `‖h_{t+1}‖ / ‖h_t‖` | **模长**变化，1 表示长度不变 |
| `rel_l2` | `‖Δ‖ / ‖h_t‖` | **方向与模长合起来**的相对变化 |
| `radial` | `(Δ·ĥ) / ‖h_t‖` | 沿原方向的分量（有符号），主要反映拉长/缩短 |
| `tangential` | `sqrt(‖Δ‖² − (Δ·ĥ)²) / ‖h_t‖` | 垂直于原方向的分量，主要反映转向 |

恒等式 `rel_l2² = radial² + tangential²` 用作实现自检；每条记录都会验证一次。

**为什么需要 `radial` / `tangential`**：`1 − cos` 对"只改长度不改方向"完全不敏感，而 `norm_ratio` 对"只转向不改长度"不敏感。分解后可以看出变化以哪一种为主。

**一个必须先说清的前提**：本模型 `use_layer_norm: true`（`model_config.yaml:24`），transformer 输出会过 `ln_final`，所以"模长"部分地是归一化的副产物，不完全是一个自由信号。但实测模长并非恒定：结果位置 6 轮内从 14.03 漂到 12.11，跨位置标准差从 0.50 增到 1.44；非结果位置从 18.19 到 16.99。**因此模长仍带信息，可以测，但解读时不能把它当成纯粹的"幅度"通道。**

## 4. 已算出节点的更新该不该消融

实测（不冻结）：节点在自己轮次之后，**下一轮还有一次明显更新**（`1−cos` 0.026–0.034，`rel_norm` 0.24–0.26），再往后基本不动（≤0.0005）。所以"算完不许更新"（第 2 节的 E / F）是有意义的对照：它检验那次后续更新对最终结果是否必要。

## 6. 判读与局限

1. **C 与 A 的差距**才是"后续逐轮更新"的贡献；B 与 C 的差距主要是第 0 轮那次变换。在没做 C 之前，现有 B 的读数不能用来支持"模型使用跨轮预计算"。
2. 所有冻结都是分布外干预，且冻结值固定为 `h_0`（或第 `start` 轮的状态），不是"某个算好的中间状态"。
3. 度量本身只说明"状态在动"，不说明"在算"。
4. `use_layer_norm: true` 使模长的解释受限（§3）。
