- 状态：设计已定，待执行结果

本文记录**打算怎么做、为什么这么做**，便于事后核查。凡涉及现有代码行为的地方都标了文件与行号。

## 1. 要回答的三个问题

| 编号 | 问题 | 对应假设 |
|---|---|---|
| Q1 | 在节点自己的轮次到达**之前**，它的隐藏向量里是否已经含有它的计算结果？ | H1 存在性 |
| Q2 | 这份信息是否由跨轮的**连续载体**承载？ | H2 载体 |
| Q3 | 这份信息是否靠**逐轮累积**形成？ | H3 形成 |

三个都用**现有权重、不重训**即可回答。

## 3. 事实前提（先核实，否则方法无意义）

1. **每轮监督覆盖整条序列的全部位置**，要求“可计算处读真值、未到轮次处读 EMPTY”。
   - `model.py:476`：`value_avail_pos = (depth_ext ≤ depth_target) & (depth_ext ≠ INVALID)`；只在这些位置把 VALUE 换成标签，其余保留输入的 EMPTY。
   - `model.py:893`：C 的每轮 `label = batch_ext[loop + 1]`，即“depth ≤ loop 填真值”。
   - 该轮损失对**展平整序列**求 CE，无位置掩码。
2. **第 t 轮的读出由第 t 次前向产出的隐藏态解码**。循环为 `h_{t+1}, preds^{(t)} = model(h_t, True)`，`h_0 = token_embedder(batch)`。
3. 因此对 depth = d 的节点 u：在 t = 0…d−1 各轮的读出**必须**是 EMPTY；到 t = d 才必须是真值。

**推论**：Q1 的问法必须落在“产出 EMPTY 读出”的那些隐藏态上——即 `h_{t+1}[u]`（t < d）。若只探 d 轮的输出，那里本来就被要求读出真值，无法区分“早有预计算”和“当场算出来”。

## 4. 探针怎么做

**样本**：对每道题、每个结果节点 u（depth d ≥ 1）、每个 t ∈ {0, …, d−1}，取特征 `h_{t+1}[u]`（384 维），标签 `T(u)`（标签里的 VALUE，0–22）。

**lead（提前量）** = d − t，取值 1…d。lead = 1 表示“上一轮就已经有信息”。

**模型**：多分类逻辑回归（23 类），在 384 维上。用闭式或 LBFGS 均可。

**切分**：按**题**切分（训练题 / 验证题各半），不按位置切分——否则同一道题的相邻位置会互相泄漏。

**基线**：
- 多数类基线（训练集最常见的 VALUE）；
- **打乱标签的探针**（把训练标签整体置换后重训），作为“能记住多少无关结构”的上界。

**报告**：验证题上按 lead 分组的准确率。**判据**：若 lead ≥ 1 的准确率显著高于打乱基线，且随 lead 减小而上升，则支持 H1；若与打乱基线无差别，则 H1 不成立。

## 5. 三个控制

### 5.1 父值改动（判“真在算”还是“只是搬运”）

对被探测的 u，选一个它的**叶子祖先** ℓ，把 ℓ 的 VALUE 改动 δ（δ ≠ 0，模 23），**按拓扑序重算全图**得到 T′(u)。重跑模型，探针读 `h_{t+1}[u]`。

- 若预测更多落在 **T′(u)** → 该位置的信息**跟随输入变化**，是真在按父值计算；
- 若预测仍落在 **T(u)** → 信息不跟随输入，提示它在搬运与输入无关的内容。

**前提检查**：重算器必须在未改动时精确复现全部标签，否则解析的图结构有误，控制无效。

### 5.2 无关叶子改动（安慰剂）

改一个**不是 u 祖先**的叶子，T(u) 不变。预期探针准确率不变。若显著下降，说明探针依赖全局扰动而非 u 本身，前面的读数不可信。

### 5.3 位置置换（负控）

用**同一个已训练探针**去读 `h_{t+1}[v]`（v 是另一道不相关节点的位置），标签仍是 T(u)。预期接近打乱基线。这检验“信息是否真的在该位置”。

## 6. 关闭信道（Q2 / Q3）

两种变体，都在推理期施加，不改权重：

| 变体 | 做法 | 检验 |
|---|---|---|
| **V1 移除载体** | 每轮前向之后执行 `h ← token_embedder(batch)`，即把跨轮输入换回离散 token 的嵌入 | H2：载体被移除后是否退化 |
| **V2 冻结未到轮次** | 每轮前向之后执行 `h[depth > t] ← h_prev[depth > t]`，只让已达轮次的位置更新 | H3：是否靠逐轮累积 |

**指标**：与现有评测一致的三项（`final_value_node_acc`、`final_value_graph_all_acc`、`final_label_full_acc`），在同一批 200 题上，与**未干预基线**比较。

**附带**：在 V1/V2 下再跑一次探针，看隐藏态里的信息是否随之消失。这比只看准确率退化更有指向性。

## 7. 已知局限（先写下来，避免事后找补）

1. **V1/V2 是分布外干预**。权重是在“连续回灌”下训练的，把载体换掉会让模型见到训练时没见过的输入。因此性能下降只能算“该通道被用到”的证据，不能量化通道贡献了多少。
2. **探针成功 ≠ 模型真的使用了该信息**。线性可解码只说明信息在，不说明下游在读。要证明因果，需要消融探针方向或注入干扰，本轮不做。
3. **叶子改动只覆盖“叶子祖先”**。若某节点没有叶子祖先（不可能，DAG 必有叶子），或改动路径使 T′(u) 与 T(u) 恰好相同（δ×路径数为 23 的倍数），该样本要剔除并计数。
4. **200 题是小样本**。lead 分组的样本量不均（深节点 lead 范围大），分组准确率要附样本数。
5. 探针是线性模型。若信息以非线性方式编码，线性探针会低估，H1 可能被误判为不成立。
