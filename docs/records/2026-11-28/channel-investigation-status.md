## 1. 研究问题（研究者 2026-11-27 提出）

离散与连续循环模型最本质的差别在**跨轮信息通道**：离散侧每轮重新嵌入 token，轮与轮之间只能传已写回的离散字段；连续侧每轮、每个位置接收上一轮的**完整向量**，而监督只约束读出、不约束隐藏向量。因此要追问：在这条监督触及不到的通道里，连续模型形成了什么机制。

研究者提出的可测方向：不允许未到轮次的向量更新（看性能是否退化）；用 `1−cos` 衡量每轮更新幅度；以及后补的"算完之后不许更新"。

## 2. 已核实的代码事实

| 事实 | 依据 |
|---|---|
| 两条损失路径都对每一轮、整条序列的全部位置求损失，无位置掩码 | `compute_batch_loss_fast`（A/B）与 `compute_batch_loss_nointerm`（C）的 `criterion` 调用 |
| 监督要求：可算处读真值，未到轮次处读 EMPTY | `model.py:476` 只在这些位置把 VALUE 换成标签；`model.py:893` `label = batch_ext[loop+1]` |
| 离散侧每轮输入是重新嵌入的 token | `compute_batch_loss_fast` 的 `batch_ext` 切片；循环版每轮 `token_embedder` |
| 连续侧每轮输入是上一轮隐藏向量 | `compute_batch_loss_nointerm` 的 `depth_batch = model(depth_batch, True)` |
| 每轮读出由该次前向产出的隐藏态解码 | 循环体 `h, preds = model(h, True)` |
| `use_layer_norm: true` | `configs/C0-M4-…/model_config.yaml:24`；但实测模长并非恒定（§4.3） |

这修正了最初的表述："监督非常不充分"不准确——监督是稠密的，但**只约束读出**；"未到轮次输出 EMPTY"等于要求模型把已知内容收进隐藏态。

## 4. 结果

### 4.1 图解析

三个种子、200 题，按"父值之和 mod 23"重算，与标签逐节点比对：**0 个失败**。

### 4.2 冻结阶梯：旧冻结的损害全部来自第 0 轮那次变换

32 题 × 3 种子（每条件 4,096 个结果位置）。条件名不复用字母，避免与模型名冲突。

| 条件 | 具体做法 | s42 | s1234 | s2026 |
|---|---|---|---:|---:|---:|
| `baseline` | 不冻结 | 0.9973 / 0.969 | 0.9797 / 0.250 | 1.0000 / 1.000 |
| `hold_unreached_from0` | 从第 0 轮起，把 `depth > t` 的结果位置每轮退回上一轮（一直停在 `h_0`） | **0.5122 / 0** | **0.7690 / 0** | **0.3923 / 0** |
| **`hold_unreached_from1`** | **第 0 轮放行（拿到 `h_1`），从第 1 轮起把 `depth > t` 的退回** | **0.9973 / 0.969** | **0.9790 / 0.250** | **1.0000 / 1.000** |
| `hold_unreached_from2` | 前两轮放行，从第 2 轮起退回 | 0.9973 / 0.969 | 0.9795 / 0.250 | 1.0000 / 1.000 |
| `hold_unreached_from3` | 前三轮放行，从第 3 轮起退回 | 0.9973 / 0.969 | 0.9797 / 0.219 | 1.0000 / 1.000 |
| `hold_computed_immediately` | 把 `depth < t`（已算出的）每轮退回，算完立刻不许再更新 | 0.9973 / 0.969 | 0.9412 / 0.031 | 0.9902 / 0.656 |
| `hold_computed_after1` | 算完允许 1 轮再退回 | 0.9973 / 0.969 | 0.9724 / 0.250 | 1.0000 / 1.000 |
| `hold_computed_after2` | 算完允许 2 轮再退回 | 0.9973 / 0.969 | 0.9788 / 0.312 | 1.0000 / 1.000 |
| `hold_unreached_from1_extra8` | 同 `hold_unreached_from1`，但多跑 8 轮 | 0.9939 / 0.875 | 0.9709 / 0.188 | 0.9998 / 0.969 |
| `hold_all_from0` | **完全冻结**：两侧都钉住，只有输入嵌入 | 0.4480 / 0 | 0.6421 / 0 | 0.3875 / 0 |
| `hold_all_from1` | **完全冻结**，但保留第 0 轮 | 0.9973 / 0.969 | 0.9324 / 0.031 | 0.9897 / 0.656 |
| `hold_all_from1_extra8` | 同上，多跑 8 轮 | 0.9973 / 0.969 | 0.9324 / 0.031 | 0.9897 / 0.656 |
| `baseline_extra8` | 不冻结，多跑 8 轮 | 0.9939 / 0.875 | 0.9666 / 0.219 | 0.9998 / 0.969 |

数值为 `node_acc / graph_all`。

四条读数：

1. **`hold_unreached_from1` ≈ `baseline`**（s42 与 s2026 完全一致，s1234 差 0.0007）。让所有位置先完成第 0 轮那次变换，**之后永远钉住也没关系**。
2. **第 1 轮之后的逐轮更新，对最终结果没有可测作用**（`from1`/`from2`/`from3` 都等于基线）。
3. **算完之后那次更新基本不必要**（`hold_computed_immediately` 在 s42 完全不掉；s1234 掉 0.039、s2026 掉 0.010；允许 1–2 轮即恢复）。
4. **多给 8 轮没有帮助**（两个 `extra8` 都等于或略低于对应的 19 轮版本），所以旧冻结的退化不是"算得不够久"。

**这取代了更早的解读**：曾把 `hold_unreached_from0` 的退化读作"未到轮次位置的更新承担实质工作"；现在明确它与 `hold_unreached_from1` 的唯一差别是第 0 轮是否施加变换，而后者完全恢复。

### 4.3 更新幅度

不冻结、三个种子一致：**最大变化在第 0 轮**（`1−cos` 约 0.40–0.46），**此后未到轮次位置每轮只有 0.012–0.018**。这一事实是 E-d 的直接起因。

按 `lead = depth − t` 的边缘趋势会显示"lead 越大变化越大"，但那是与轮次混杂造成（大 lead 只可能出现在早期轮次）；加入（轮次 × lead）交叉表后证伪。

已算出节点：`lead=−1` 时 `1−cos` 0.026–0.034、`rel_norm` 0.24–0.26；`lead=−2` 降到 0.002–0.003；`lead≤−3` 约 0.0005。即算完后下一轮还有一次明显更新，之后基本冻结；而 E 条件表明这次更新基本不必要。

度量口径：`rel_l2² = radial² + tangential²` 每条记录自检，误差约 4×10⁻⁷。`use_layer_norm: true`，但实测模长并非恒定（结果位置 6 轮内 14.03→12.11，跨位置标准差 0.50→1.44），模长仍带信息。

### 4.4 提前量 g 的扫描（8 题，已被 §4.2 取代，仅存档）

| 种子 | 不冻结 | g=0 | g=1 | g=2 | g=3 | g=4 |
|---|---:|---:|---:|---:|---:|---:|
| 42 | 1.0000 | 0.5166 | 0.6426 | 0.7461 | 0.8154 | 0.8955 |
| 1234 | 0.9805 | 0.7959 | 0.8076 | 0.8740 | 0.9043 | 0.9580 |
| 2026 | 1.0000 | 0.4326 | 0.5244 | 0.6260 | 0.7393 | 0.8330 |

单调回升，但即使 g=4 也未回到基线；而 C 完全回到基线。说明关键在于"有没有拿到第 0 轮那次变换"，不在"能提前几轮"。

## 6. 能下的结论 / 不能下的结论

**能下**

1. 跨轮载体确实被用到：只保留第 0 轮的写入、之后不再更新，模型仍与基线相同。
2. 第 1 轮之后的逐轮更新对最终结果没有可测作用；算完之后那次更新也基本不必要。
3. 信息是在第 0 轮那次前向里写进隐藏态的，此后基本原样携带，不是逐轮累积。
4. 三个种子基线差异很大（整图全对率 0.250–1.000），跨条件比较必须逐种子报告。

**不能下**

1. 不能说隐藏态里"有什么/没有什么"——本轮没测隐藏态内容与其可解码性。
2. 不能把 8 题的绝对精度当稳定值——200 题版本未取得。
3. 不能用这些结果推断 D（连续 + 纠错）会怎样——D 还没训。
