## 1. 研究问题（研究者 2026-11-27 提出）

离散与连续循环模型最本质的差别在**跨轮信息通道**：

- 离散侧每轮重新嵌入 token，轮与轮之间只能传已写回的离散字段；
- 连续侧每轮、每个位置接收上一轮的**完整向量**，而监督只约束读出、不约束隐藏向量。

因此要追问：**在这条监督触及不到的通道里，连续模型形成了什么机制？** 并预期因缺少直接监督，该机制有较大随机性，需要多种子与充分训练才能看出。

研究者同时提出两个可测方向：**不允许未到轮次的向量更新**（看性能是否退化）；以及后来补充的**用 `1−cos` 衡量每轮更新幅度**。

## 2. 已核实的代码事实（不是推测）

| 事实 | 依据 |
|---|---|
| 两条损失路径都对**每一轮、整条序列的全部位置**求损失，无位置掩码 | `compute_batch_loss_fast`（A/B）与 `compute_batch_loss_nointerm`（C）的 `criterion` 调用 |
| 监督要求：可算处读真值，**未到轮次处读 EMPTY** | `model.py:476` 只在这些位置把 VALUE 换成标签，其余保留输入的 EMPTY；`model.py:893` `label = batch_ext[loop+1]` |
| 离散侧每轮输入是**重新嵌入的 token** | `compute_batch_loss_fast` 的 `batch_ext` 切片；循环版每轮 `token_embedder` |
| 连续侧每轮输入是**上一轮隐藏向量** | `compute_batch_loss_nointerm` 的 `depth_batch = model(depth_batch, True)` |
| 每轮读出由该次前向产出的隐藏态解码 | 循环体：`h, preds = model(h, True)` |
| 模型 `use_layer_norm: true`，输出过 `ln_final` | `configs/C0-M4-…/model_config.yaml:24`；但实测模长并非恒定（见 §5.4） |

**这修正了最初的表述**："监督非常不充分"不准确——监督是稠密的（每位置每轮都有），但它**只约束读出**；且"未到轮次输出 EMPTY"等于要求模型把已知内容收进隐藏态。

## 4. 关键结果

### 4.1 图解析（所有干预的前提）

三个种子、200 题，按"父值之和 mod 23"重算，与标签逐节点比对：**0 个失败**。

### 4.2 线性探针：**未能判定 H1**

| 种子 | 基线 node_acc | val acc | **train acc** | 打乱标签 | 多数类 |
|---|---:|---:|---:|---:|---:|
| 42 | 0.994297 | 0.0403 | **0.2122** | 0.0441 | 0.0428 |
| 1234 | 0.977148 | 0.0454 | **0.2213** | 0.0414 | 0.0402 |
| 2026 | 0.999883 | 0.0434 | **0.1858** | 0.0446 | 0.0451 |

23 类随机水平 0.0435。按 lead 分组无趋势。

**关键在 train acc**：只有 0.19–0.22，说明探针**在训练集上就没拟合住**，属欠拟合。所以不能读作"隐藏态里没有信息"，只能读作"384 维线性探针解不出来"。

父值改动控制同样因探针在随机水平而无效（`pred_equals_new` 0.061/0.020/0.060，`pred_equals_old` 0.020/0.120/0.040，n≈50）。

### 4.3 冻结阶梯：**旧冻结的损害全部来自第 0 轮那次变换**

`node_acc / graph_all`：

| 条件 | 说明 | s42 | s1234 | s2026 |
|---|---|---|---:|---:|---:|
| A | 不冻结 | 1.0000/1.000 | 0.9805/0.250 | 1.0000/1.000 |
| B | 从第 0 轮起冻结（旧做法） | **0.5166/0** | **0.7959/0** | **0.4326/0** |
| **C** | **第 0 轮不冻结，之后一直钉住** | **1.0000/1.000** | **0.9795/0.250** | **1.0000/1.000** |
| D2 | 第 2 轮起才冻结 | 1.0000/1.000 | 0.9805/0.250 | 1.0000/1.000 |
| D3 | 第 3 轮起才冻结 | 1.0000/1.000 | 0.9805/0.250 | 1.0000/1.000 |
| E | **算完立刻不许再更新** | 1.0000/1.000 | 0.9502/0.125 | 0.9941/0.500 |
| F1 | 算完允许 1 轮再钉住 | 1.0000/1.000 | 0.9775/0.250 | 1.0000/1.000 |
| F2 | 算完允许 2 轮再钉住 | 1.0000/1.000 | 0.9775/0.250 | 1.0000/1.000 |
| G | C + 多 8 轮 | 0.9932/0.875 | 0.9814/0.375 | 0.9990/0.875 |
| A8 | 不冻结 + 多 8 轮 | 0.9971/0.875 | 0.9766/0.375 | 1.0000/1.000 |

**四条读数**：

1. **C ≈ A**（s1234 差 0.001，另两个完全一致）。让所有位置先完成第 0 轮那次变换，之后**永远钉住也没关系**。
2. **第 1 轮之后的逐轮更新对最终结果没有可测作用**（C、D2、D3 都等于 A）。
3. **算完之后那次更新基本不必要**（E 在 s42 完全不掉；s1234 掉 0.030、s2026 掉 0.006）。
4. **多给 8 轮没有帮助**（G、A8 与 A 相当或略低），所以旧冻结的退化不是"算得不够久"。

**这取代了先前的解读**：曾把 B 的退化读作"未到轮次位置的更新承担实质工作"，并猜想过"注意力跨位置污染"。现在两组都不需要：B 与 C 的唯一差别是第 0 轮是否施加变换，C 完全恢复。

### 4.4 更新幅度（方向 / 模长 / 总量）

不冻结、seed 42：

| 量 | t=0 | t≥1（未到轮次位置） |
|---|---|---|
| `1−cos`（方向） | **0.4045** | 0.012–0.018 |
| 按 lead（同一轮次内更细的切片） | lead=0：0.111 | lead≥1：0.0004–0.011 |

三个种子一致：**最大变化发生在第 0 轮，此后小两个数量级**——这正是研究者指出、并促成阶梯实验的那个事实。

按 lead 的**边缘**趋势会显示"lead 越大变化越大"（seed 42：lead1 0.032 → lead10 0.251），但那是**与轮次混杂**造成的：大 lead 只可能出现在早期轮次。加入（轮次 × lead）交叉表后证伪。

**已算出节点**（lead<0，不冻结）：lead=−1 时 `1−cos` 0.026–0.034、`rel_norm` 0.24–0.26；lead=−2 降到 0.002–0.003；lead≤−3 约 0.0005。即**算完后下一轮还有一次明显更新，之后基本冻结**——而 E 条件表明这次更新基本不必要。

**度量口径**：`rel_l2² = radial² + tangential²` 在每条记录上自检，误差约 4×10⁻⁷。模型 `use_layer_norm: true`，但实测模长并非恒定（结果位置 6 轮内 14.03→12.11，跨位置标准差 0.50→1.44），所以模长仍带信息，只是解读时不能当成纯粹的"幅度"通道。

### 4.5 冻结的提前量 g（这一项已被 §4.3 取代，仅存档）

允许 g 轮提前量时的 `node_acc`：

| 种子 | 不冻结 | g=0 | g=1 | g=2 | g=3 | g=4 |
|---|---:|---:|---:|---:|---:|---:|
| 42 | 1.0000 | 0.5166 | 0.6426 | 0.7461 | 0.8154 | 0.8955 |
| 1234 | 0.9805 | 0.7959 | 0.8076 | 0.8740 | 0.9043 | 0.9580 |
| 2026 | 1.0000 | 0.4326 | 0.5244 | 0.6260 | 0.7393 | 0.8330 |

单调回升，但**即使 g=4 也未回到基线**；而 C（第 0 轮不冻结、之后永远钉住）完全回到基线。两者对照说明：**关键在于"有没有拿到第 0 轮那次变换"，不在于"能提前几轮"。**

## 5. 出过的错误与撤回（完整清单）

| 项 | 情况 |
|---|---|
| 把 OOM 归因于 batch 过大 | 错。是启动时 GPU 被他人占用；80G 足够 |
| 把 0.046875 读作"模型塌成常数" | 错。实测 976/1024 个位置输出 EMPTY，即"没算" |
| `rewrite` 变体当作 A/B 的离散条件 | 错。写回的多为 EMPTY，模型面对"VARIABLE+已填值"仍输出 EMPTY，未构成通道 |
| `reembed` 变体 | 与 `rewrite` 实质同效，已撤回 |
| 第一次探针读数（4 题，train 1.0 / val 随机）读作"无信号" | 错。是过拟合 |
| 第二次探针读数（200 题，train 0.19–0.22） | 本次是欠拟合，正确做法是先做可行性自检 |
| 按 lead 的边缘趋势 | 与轮次混杂，已被交叉表证伪 |
| B 的退化读作"未到轮次的更新承担实质工作" | 错。已被 C 条件推翻 |
| 猜想过"注意力跨位置污染" | 未验证，且 §4.3 之后不再需要 |
| 归档放在 `data/` 下 | 被 `.gitignore` 的 `**data/` 忽略，未进提交；已改名为 `json/` |

## 6. 目前能下的结论 / 不能下的结论

**能下（有测量支撑）**

1. 跨轮载体**确实被用到**：让它只保留第 0 轮的写入、之后不再更新，模型仍与基线相同；而**完全移除载体**（E-d，虽已撤回，其"输出 EMPTY"的现象仍成立）会让模型基本不产出值。
2. **第 1 轮之后的逐轮更新对最终结果没有可测作用**；算完之后那次更新也基本不必要。
3. 信息是**在第 0 轮那次前向里写进隐藏态的，此后基本原样携带**，不是逐轮累积。
4. 三个种子的基线差异很大（整图全对率 0.345–0.985，`graph_all`），任何跨条件比较必须逐种子报告。

**不能下**

1. **不能说"隐藏态里没有该节点的结果"**——线性探针欠拟合，H1 未判定。
2. **不能说"信息在哪些维度/以什么形式编码"**——探针与度量都只说"状态在动"。
3. **不能把 8 题的绝对精度当稳定值**——200 题版本未取得。
4. **不能用这些结果推断 D（连续+纠错）会怎样**——D 还没训。

## 7. 未解决的点

1. H1（`h₁` 里是否已含该节点结果）未判定；线性探针欠拟合。
2. 父值改动控制因此在当前探针下无效，依赖 H1。
3. 200 题冻结扫描未取得（两次 OOM）。
4. 所有精度只基于 8 题（1,024 个结果位置）。
5. `use_layer_norm` 使"模长"的解释受限。
