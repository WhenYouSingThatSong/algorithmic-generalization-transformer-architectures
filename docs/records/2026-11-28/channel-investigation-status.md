## 1. 研究问题（研究者 2026-11-27 提出）

离散与连续循环模型最本质的差别在**跨轮信息通道**：离散侧每轮重新嵌入 token，轮与轮之间只能传已写回的离散字段；连续侧每轮、每个位置接收上一轮的**完整向量**，而监督只约束读出、不约束隐藏向量。因此要追问：在这条监督触及不到的通道里，连续模型形成了什么机制。

研究者提出的可测方向：不允许未到轮次的向量更新（看性能是否退化）；用 `1−cos` 衡量每轮更新幅度；以及后补的"算完之后不许更新"。

## 2. 已核实的代码事实

| 事实 | 依据 |
|---|---|
| 两条损失路径都对每一轮、整条序列的全部位置求损失，无位置掩码 | `compute_batch_loss_fast`（A/B）与 `compute_batch_loss_nointerm`（C）的 `criterion` 调用 |
| 监督要求：可算处读真值，未到轮次处读 EMPTY | `model.py:476` 只在这些位置把 VALUE 换成标签；`model.py:893` `label = batch_ext[loop+1]` |
| 离散侧每轮输入是重新嵌入的 token | `compute_batch_loss_fast` 的 `batch_ext` 切片；循环版每轮 `token_embedder` |
| 连续侧每轮输入是上一轮隐藏向量 | `compute_batch_loss_nointerm` 的 `depth_batch = model(depth_batch, True)` |
| 每轮读出由该次前向产出的隐藏态解码 | 循环体 `h, preds = model(h, True)` |
| `use_layer_norm: true` | `configs/C0-M4-…/model_config.yaml:24`；但实测模长并非恒定（§4.3） |

这修正了最初的表述："监督非常不充分"不准确——监督是稠密的，但**只约束读出**；"未到轮次输出 EMPTY"等于要求模型把已知内容收进隐藏态。

## 4. 结果

### 4.1 图解析

三个种子、200 题，按"父值之和 mod 23"重算，与标签逐节点比对：**0 个失败**。

### 4.2 冻结阶梯：旧冻结的损害全部来自第 0 轮那次变换

`node_acc / graph_all`：

| 条件 | 说明 | s42 | s1234 | s2026 |
|---|---|---|---:|---:|---:|
| A | 不冻结 | 1.0000/1.000 | 0.9805/0.250 | 1.0000/1.000 |
| B | 从第 0 轮起冻结（旧做法） | **0.5166/0** | **0.7959/0** | **0.4326/0** |
| **C** | **第 0 轮不冻结，之后一直钉住** | **1.0000/1.000** | **0.9795/0.250** | **1.0000/1.000** |
| D2 | 第 2 轮起才冻结 | 1.0000/1.000 | 0.9805/0.250 | 1.0000/1.000 |
| D3 | 第 3 轮起才冻结 | 1.0000/1.000 | 0.9805/0.250 | 1.0000/1.000 |
| E | **算完立刻不许再更新** | 1.0000/1.000 | 0.9502/0.125 | 0.9941/0.500 |
| F1 | 算完允许 1 轮再钉住 | 1.0000/1.000 | 0.9775/0.250 | 1.0000/1.000 |
| F2 | 算完允许 2 轮再钉住 | 1.0000/1.000 | 0.9775/0.250 | 1.0000/1.000 |
| G | C + 多 8 轮 | 0.9932/0.875 | 0.9814/0.375 | 0.9990/0.875 |
| A8 | 不冻结 + 多 8 轮 | 0.9971/0.875 | 0.9766/0.375 | 1.0000/1.000 |

四条读数：

1. **C ≈ A**（s1234 差 0.001）。让所有位置先完成第 0 轮那次变换，之后**永远钉住也没关系**。
2. **第 1 轮之后的逐轮更新，对最终结果没有可测作用**。
3. **算完之后那次更新基本不必要**（E 在 s42 完全不掉；s1234 掉 0.030、s2026 掉 0.006）。
4. **多给 8 轮没有帮助**，所以旧冻结的退化不是"算得不够久"。

这取代了 E-b 的解读：曾把 B 的退化读作"未到轮次位置的更新承担实质工作"；现在明确 B 与 C 的唯一差别是第 0 轮是否施加变换。

### 4.3 更新幅度

不冻结、三个种子一致：**最大变化在第 0 轮**（`1−cos` 约 0.40–0.46），**此后未到轮次位置每轮只有 0.012–0.018**。这一事实是 E-d 的直接起因。

按 `lead = depth − t` 的边缘趋势会显示"lead 越大变化越大"，但那是与轮次混杂造成（大 lead 只可能出现在早期轮次）；加入（轮次 × lead）交叉表后证伪。

已算出节点：`lead=−1` 时 `1−cos` 0.026–0.034、`rel_norm` 0.24–0.26；`lead=−2` 降到 0.002–0.003；`lead≤−3` 约 0.0005。即算完后下一轮还有一次明显更新，之后基本冻结；而 E 条件表明这次更新基本不必要。

度量口径：`rel_l2² = radial² + tangential²` 每条记录自检，误差约 4×10⁻⁷。`use_layer_norm: true`，但实测模长并非恒定（结果位置 6 轮内 14.03→12.11，跨位置标准差 0.50→1.44），模长仍带信息。

|---|---:|---:|---:|---:|---:|---:|
| 42 | 1.0000 | 0.5166 | 0.6426 | 0.7461 | 0.8154 | 0.8955 |

## 6. 能下的结论 / 不能下的结论

**能下**

1. 跨轮载体确实被用到：只保留第 0 轮的写入、之后不再更新，模型仍与基线相同。
2. 第 1 轮之后的逐轮更新对最终结果没有可测作用；算完之后那次更新也基本不必要。
3. 信息是在第 0 轮那次前向里写进隐藏态的，此后基本原样携带，不是逐轮累积。
4. 三个种子基线差异很大（整图全对率 0.250–1.000），跨条件比较必须逐种子报告。

**不能下**

1. 不能说隐藏态里"有什么/没有什么"——本轮没测隐藏态内容与其可解码性。
2. 不能把 8 题的绝对精度当稳定值——200 题版本未取得。
3. 不能用这些结果推断 D（连续 + 纠错）会怎样——D 还没训。

## 7. 未解决

1. 200 题冻结阶梯未取得（两次 OOM）。
2. 精度只基于 8 题（1,024 个结果位置）。
3. `use_layer_norm` 使模长解释受限。
4. "信息在第 0 轮写入"具体写在哪些位置、以什么形式，本轮没有测。
