# C（多时点局部纠错、第二层更新监督，正常窗口）种子 42、1234 正式评测

2026 年 11 月 21 日执行版。核对复现分支 cdb6be1。第四格基础研究另见[研究清单](research-checklist.md)。本批正式评测仅使用种子 42、1234 各自第 50 个后训练周期的权重。现有交付包括三个权重、干净开发集及拟合历史；正式六档分类汇总待回传。两份终点权重在已有 128 张开发图上均为整图数值全对。种子 2026 在同一指标上为 71/128，保留其训练及开发集记录。本批按基础拟合筛选，结果仅概括入选两份权重。

## 1. 模型具体受到了什么监督

每轮接收上轮连续向量，四层模型的第二层读出“应更新”，末层给出各字段。第二层目标来自本轮可读的直接父值：父值齐备时，旧值空或与当地算式不符就应更新。间接影响在父值变化后才成为直接冲突。末层另受计算结果、更新预测与实际改动一致性及清除标记的监督。所有位置均执行前向。新可算、求解中、实际完成后三种训练机会等概率；完成后须在规定时点整图数值全对。训练在标准求解轮数加一的预算内结束。长窗口是评测外推。

## 2. 冻结的题目和干预矩阵

六档为 32、64、128 节点分别配最大依赖深度 ≤6 和 7–12。每档 128 图基础能力，共 768 张共同测试图；每档预定的前 32 图进入重点分类，共 192 张候选图。两个模型用同一批图。每条成功干预追踪后续 16 轮。每时点独立给出机会数、起点资格、供体拒绝、实际执行及各目标的实际输入改变数。

| 起点 | 现有重点条件 | 解释时的要求 |
|---|---|---|
| 结构上刚可算 | 同起点干净、单点合理错值 | 保留改前为空、正确和已有错值的实际状态 |
| 计算中途 | 干净、单点错值 | 人工注错限整题尚未完成、选定目标已经正确。训练中途的抽样允许其他起点，另列覆盖 |
| 标准求解轮数 | 干净、单点错值 | 此处的完成后注错须当时整图数值全对；报告固定预算内未完成图 |
| 标准轮数加 16 轮内首次整图数值全对 | 干净、单点错、父子局部一致却全局错误、独立位置恢复历史空值、空值与错值同时出现 | 这是按事件对齐的起点。相同图若也满足上一行，只作配对分析。单独列无法找到同身份历史空向量的图 |

通用评测另含持续污染、噪声、新消费者等适用分支。冻结原 C 的功能探针在 32、128 节点档有限定覆盖。冻结探针检验注入向量能否驱动另一模型的计算，与后训练模型自身的恢复分开。

## 3. 建议正式报告固定六张表

| 表 | 首要问题 | 分母和结果 |
|---|---|---|
| ① 干净能力与拟合 | 基础题是否会算，长跑是否出现代价？ | 六档逐种子。逐图等权节点数值、节点四字段同时正确率，配整图数值全对、变量名漂移、错节点分布。列标准预算、标准后若干轮及训练曲线、末周期平均训练损失。固定终点作正式结果，匹配拟合只作额外解释 |
| ② 第二层定位 | 在哪些实际输入上标出待更新？ | 新可算仍空、直接冲突、健康、局部一致但全局错、父值未齐、其他非数字各给机会数。需更新组报命中数／应更新数；健康组报误报数／健康数。另给所有预测更新中的正确比例。首轮与全窗分列 |
| ③ 末层执行 | 标记有无落实，算对了哪一种答案？ | 同一节点同一轮同时列预测、实际数值改变、末层等于按当前父值算出的局部目标、末层等于原题真值。报告联合数，着重拆开目标原本全局正确／错误两种直接冲突 |
| ④ 恢复与传播 | 目标、直接子节点、其他受影响节点各错多久？ | 从全部实际注错起算单列首轮修回。另从确已受损者起算，报首次回正、回正再错和注错后第 15、16 轮均正确。记录同起点干净续算仍正确、受扰续算却错的节点×轮。自然漂移、自然恢复另表，不与注错事件合并 |
| ⑤ 同图混合 | 同一轮能否新算、纠错并保住健康位置？ | 分“空值单独、错值单独、两者同时、干净”四臂，在同图共同合格子集配对。列实际三类同时出现图数，再列三类各自成功、三类同时成功。局部计划执行全对与三类任务真值全对分别报告 |
| ⑥ 修回后是否可用 | 目标读回正确后，新消费者真的用对吗？ | 在无扰动分支新消费者能算对的图上，列目标读出对／错 × 新消费者末两轮对／错四格，报全候选与合格分母。早已受损下游的恢复另列；两个消费者在修正前后首次使用同一值属于后续新增配对实验 |

**示例。** 原题 a=3、b=4、u=7。本轮输入若为 (3,4,9)，标更新、改回 7，局部与全局同时成功。若为 (5,4,7)，标更新、改成 9，定位命中、执行局部正确，但原本正确的节点被改坏。若为 (5,4,9)，按直接父值无须改，原题仍错；追踪父值回正后哪一轮出现直接冲突、是否随之修回。三个现场放在一起才能解释第二层到底学到了什么。要归因于第二层信号驱动实际更新，仍需干预通路或匹配训练消融。

## 4. 现有代码可以交付什么，哪里需要补

- **已实现。** assess.py 负责四时点、五种首次完成条件、固定权重和同起点对照。scenarios.py 按实际父值分类，已有定位、局部及全局正确计数、混合首轮、恢复和再错、逐图等权及合并计数。outcomes.py 已计算自然漂移及新消费者四格。
- **首先汇集已有文件。** cohort.py 仅从每档重点分类摘要取逐图等权行，从标准摘要取三项干净指标。每档覆盖、混合图计数、自然漂移和新消费者等保存在单独文件。原汇总缺行不等于没有跑；先读各分档结果。空分母写“无合格事件”。
- **两个须避免的错读。** 重点分类里 direct_conflict 同时覆盖目标错父对、目标对父错等情况；现有分类汇总无法直接分开。组合干预的 actual_value_changed 读的是主目标 p，即使只在另一个位置填入历史空向量，标志仍可能为假。应分别记录被清空位置、被写错位置、受影响父子各自的实际输入变化。此标志不能充当整次混合注错成功的分母。
- **补数据的判据。** 先从已有标准逐轮输入输出重算所覆盖条件。重点分类文件保存每图分类计数、阶段和终点，不能从边际计数推得未保存的节点级交集。确实缺失时，对原清单相应小分支额外记录：图、位置、轮次、干净与干预输入、父值及就绪性、局部目标、全局真值、第二层预测、末层输出、角色。只需置信度时保留正确值与最强错误值的概率，不用保存整份隐藏状态。建议采用独立补充入口和输出目录；冻结清单校验已有代码哈希。
- **展示口径。** 分类代码的 mixed 指当次输入真实具备三类，联合成功依据局部目标和计划；不能据此声称原题三类全对。标准轮数末与追加预算的界线标明绝对轮次，避免把重叠边界当成两次独立事件。不能从两列正确率乘积推导联合恢复。
- **推断。** 六档固定报告每种子和配对图的样本量。正式结论先回答这个版本在这些条件下怎样更新。比较其他训练版本时，配对原始种子、题目、预算、干净拟合及实际损伤；未经匹配的差异只作行为描述。

## 5. 审阅后可独立加入的扩展

1. 同一父值、两个使用时点：旧下游曾用过错误值，新下游在修正后首次就绪。追踪两者以区分拦截、保护未来和清除旧损伤。
2. 显式改变可信证据：局部冲突相同的两道题分别构造暂时父值受扰和合法题面修改，检验模型是否拥有足以辨认两者的信息。
3. 正确与错误候选的置信度曲线：分别统计正确答案越来越稳和错误答案越来越稳，验证它能否预测再错或新的下游损伤。

## 六张表的实际生成命令

Agent B 完成两份权重的 assess 后，从仓库根目录执行下列 CPU 命令。保留原始逐图 standard.jsonl 和 classes.json。report 校验两份权重及清单，读取六档固定图，输出六份 UTF-8 CSV。输出目录必须为新目录，缺失或不匹配时不发布半成品。

```bash
root=tmp/analysis/c-local-update-normal-v1
python tools/c_selected_eval.py report --results "$root/eval/C_s42" "$root/eval/C_s1234" --out-dir "$root/selected-tables"
```

若已有的旧版重点分类结果缺少首轮每个位置的对错或直接冲突联合计数，使用下面的补采路径。只对缺项权重运行 focused，它沿用冻结图和时点，跳过已含新版明细的数据档。每张图在同一个时点的四个条件共享起点，补采以完整重点分档为单位。标准能力、持续干扰、新消费者及训练全部复用原产物。

```bash
plan=tmp/analysis/c-update-20261119/data/plan.json
for model in C_s42 C_s1234; do
  python tools/c_selected_eval.py focused --model "$model" --checkpoint "$root/train/$model/final.ckpt" --plan "$plan" --manifest "$root/manifest.json" --existing "$root/eval/$model" --out-dir "$root/report-supplements/$model"
done
python tools/c_selected_eval.py report --results "$root/eval/C_s42" "$root/eval/C_s1234" --supplements "$root/report-supplements" --out-dir "$root/selected-tables"
```

交付 01 至 06 六份 CSV，各种子、各数据档单列。训练曲线行以周期为单位。定位分类同时报逐图等权与节点计数合并比例。第四表标准干预和自然轨迹的合并计数沿用冻结产物，逐图均值栏留空；自然轨迹的两个窗口共享标准求解后第 1 轮边界。第五表只在同图四臂齐全、目标和清空位置及起始轮一致时作比较，另报全部候选覆盖。第六表记录新增算式前目标的读出和新下游末两轮表现，另列冻结原始 C 接收向量的功能探针。无分母比率留空。未在该规模登记的新消费者实验明确标为未登记。架构归因、置信度和双使用时点的新实验仍按讨论稿独立安排。
