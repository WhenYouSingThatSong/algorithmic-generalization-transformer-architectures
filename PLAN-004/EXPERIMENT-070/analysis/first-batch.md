# 第一批 · 原始 C 的恢复机制与纠错后训练的行为收益

本批使用已有权重，在同一模 23 加法任务上回答五个问题。主四组为离散 A′、离散 B、原始 C、只在新可算位置训练纠错的 C。多时点纠错与第二层过程监督的 C 单列。离散种子 42，连续种子 42、1234 分别报告。两套后训练均与自己起点的原始 C 配对。实现与算术参考检查已交付，模型结果待服务器运行。

## 实验与判据

| 候选 | 输入、操作与对照 | 主要交付和读法 |
|---|---|---|
| 1 · 自然错与同值人工错 | 使用原始 C 的 192 张标准图和归档中的自然错边。按原先固定顺序，每图最多四条可回放边，保留先前回放能救和不能救的两类。重现出错前后同一节点与子节点的读数，用改动题面常数的配对图生成同位置、同绝对轮次、同一确切错数的供体，并核对其余三个字段。 | 在同一现场分别保留自然错向量、换成人工同错数向量、放回此前正确的目标向量。分别保持周围状态原样、仅恢复错误父节点、恢复其余已到求解轮次的错误节点。每个恢复位置记录实际历史来源；其他位置无法找到正确历史时记录缺口。三种背景各自自由续算 16 轮。比较子节点首次采用特定错值、目标与子节点末两轮共同正确。若实际恢复位置数为零，该分支只是对照。修复周围状态是人为操作，报告其范围。 |
| 3 · 相同读数、不同历史 | 两份原始 C 同一题、同一位置、同一绝对轮。分别取稳定正确、持续置空后首次填对、先读出错数再恢复正确的三种向量。严格核对之前与当前读数及其他三个字段。在共同的稳定前缀后追加一个从未参与前轮计算的新子节点，只交换前缀中目标位置，观察它首次读取与随后表现。另换入确切错值作为阳性对照。 | 输出每臂资格、共同资格、向量实际改变量。依次报告所有共同合格题，以及原样读对且错值对照确被新子节点采用的题。对比新读者在数值完全相同时会不会因目标的计算历史不同而改答。延迟与受扰历史由实验构造。 |
| 5 · 正式同题主四组 | 把两种后训练 C 的两个种子接入此前的 192 张标准图、32 张分层图、64 张扩展题，保持各场景、写入、搜索窗口与旧实验一致。读取已交付的 A′、B 和原始 C 轨迹。 | 给出按模型自身资格、组内共同资格、同绝对轮次、标准组再限同题基础拟合的表。C 版本间另有两组种子内配对。输出原始计数、每图资格与成对“不一致方向”计数。不同种子的连续模型与同一对离散模型的比较分表，不计作两次独立离散复现。 |
| 6 · 局部恢复与下游代价 | 另在固定 64 张题的三种拓扑中只改一个内部位置，让一、二或四个直接子节点使用它。时点为目标刚可算、目标刚算对而子节点尚空、子节点均已算对、整图数值已全对。保留不改的同题分支，八份权重同条件运行。 | 记录目标首次回正、首次有子节点按错值更新的轮次、采用该错值的子节点数、所有后代额外出错数的节点轮数、额外空值节点轮数、指定终点是否曾经及最终受损。持续恢复只在确实传播且还留两轮的事件上计算。干净分支本来有正确答案才计额外损伤。 |
| 9 · 第二层检错标出 | 只测多时点加第二层监督的 C。重复测第 10、30 周期和第 50 周期最终权重。按实际输入，在干净、改目标、改父节点、同图同时清空和改错的条件下，对每个内部位置保存第二层标记概率、本轮之前的数值、本轮输出、原题正确值和由当前父值推出的值。 | 按应新填、已填直接冲突、健康、与错误父值一致、父值未就绪等实际状态分别汇总，目标与其他位置分表。预设阈值 0.1、0.25、0.5、0.75、0.9；主阈值 0.5，同时看命中、漏标但修对、健康误报和实际修改。逐周期对照可检验“检错标出能力欠拟合”的解释。三种训练阶段用同样测试图，只作诊断。 |

### 对照与分母

1. 标准组的同题拟合表含常规预算、再四轮、再十六轮的节点数值与前四字段。最严格共同子集要求四方同一干预轮且常规预算再四轮时同题整图数值均对。大图无共同合格题时保留候选数与零覆盖。分层及扩展组用其原协议，不填写不存在的标准组拟合数据。扩展组主表沿用数值资格，原始文件另存逐次写入的四字段资格。
2. 空值、读出某个错误数字、下游用到了**特定**错值分别报告。传播条件下的恢复率分母只含已传播且余窗足够的事件；从全部合格注错事件出发的下游风险另报。首次回正和首次特定传播的轮次求和分别除以确实发生该事件的题数。分支数配对先按相同题号与链长取交集。
3. 自然错报告从所有机会、节点错值事件、现有回放边、找到同错数供体、原轨迹重现依次列覆盖。分列同数供体失败和背景修复失败。报告所称自然错仅指先正确后变为另一个数字。不能用筛过的可回放边估计所有自然错误的恢复概率。
4. 对照相同基础拟合时，同时附每模型的训练曲线、末周期损失（注明目标）与同题干净读数。来源位置由每个运行目录的 `fit-source.json` 及[已有拟合资料](../2026-11-21/c-local-update-fit-history.md)给出；离散或原始权重缺失的日志由服务器执行者按 checkpoint 身份查找，无法取得则标出缺项。现有权重的训练预算有差异。

## 执行顺序与交付

在 `reproduction` 的固定快照执行。两个 worker 使用各自 GPU 和工作树，数据根只读，`FIRST_BATCH_OUT` 指向同一个新的绝对输出根，各 worker 写不同 stage/model 子目录。与旧作业目录分开。下列入口按角色顺序运行，不启动训练。

```bash
export DATA_ROOT=/实际路径/训练数据工作树
export FIRST_BATCH_OUT=/实际路径/first-batch-20261123
# Agent C：原始连续模型的自然错及同值向量，再跑原始模型和离散模型的分支传播
bash tools/c_hard_graphs/run_first_batch.sh original smoke
bash tools/c_hard_graphs/run_first_batch.sh original formal
# Agent B：中间监督各周期，之后两类后训练的同题重放及分支传播
bash tools/c_hard_graphs/run_first_batch.sh trained smoke
bash tools/c_hard_graphs/run_first_batch.sh trained formal
# 双方小测齐备可运行 report smoke；正式产物齐备后由 Agent B 单独汇总
bash tools/c_hard_graphs/run_first_batch.sh report formal
```

每个模型和阶段都核对来源权重、配置与输出身份。兼容的已落盘图按题续跑；评估文件按题原子写入。第 10、30 周期读取原训练保存的 checkpoint 并核对内部种子、轮次、训练身份。对应文件未交接齐时可直接调用 `first_batch.py --models ... --stages ...` 完成其余独立实验，并报告具体缺项。

**验收**：C 侧交自然错覆盖、同值与错值对照的实际读数、至少一个满足条件的真实配对轨迹（零覆盖时列原因）；B 侧交标准／分层／扩展完整性、分阶段的标记与输出、同图健康误报、真实修回但下游受损与未受损的样例。汇总脚本读取全部预定正式题；提交各比较的分子、分母、按种子与图规模的表，显式说明零分母或同题拟合缺口。批量原始轨迹留运行目录，交付记录写权重、命令、哈希、原始文件路径与观察；看板、日志在 `reproduction` 追加。
