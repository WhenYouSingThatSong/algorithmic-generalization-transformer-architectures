# 模型第一次计算前，图上已经填了数会怎样？

每个节点有一个存放计算结果的位置。在第一次前向之前，只改该位置的 VALUE。题面常数、算式、变量名、表达式中对变量的引用均保留。例如题面给定“源节点等于 3”，可以把源节点的结果格预填为 8，模型仍可从原题读到 3。所有初始值一次准备好，随后自由计算 24 轮。

| 输入条件 | 构造 |
| --- | --- |
| 全空 | 原题，所有结果格留空，作为每个权重自己的同题对照 |
| 全图随机选位置 | 分别预填恰好 25%、50%、75%、100% 的节点，其余留空 |
| 指定位置类别 | 分别只预填源节点、有下游的中间节点、没有下游的非源节点 |

预填数字在 0 至 22 间均匀抽取，保留碰巧正确的数字。每张底图用三次独立抽样。单次抽样中各密度使用嵌套位置，重复命中同一节点时写入相同数字；同图两种排列及所有权重复用相同抽样。沿用实验 072 的 36 张底图、两种排列和五份权重。每份权重有 72 个全空对照、1,512 个预填输入；独立底图数为 36。

从仓库根目录依次执行，输出在 tmp/analysis/plan008-exp073 的 smoke 和 formal 子目录。

```bash
python PLAN-008/EXPERIMENT-073/prefill.py --check-design
python PLAN-008/EXPERIMENT-073/prefill.py --smoke
python PLAN-008/EXPERIMENT-073/prefill.py
```

**验收与读数**

1. 每份权重各交一份压缩逐题轨迹和分层计数表。全空记录含算式、节点真值、父节点和位置；每条预填记录含实际初值及每轮全部节点的数值读出。各模型同一题、同一初值可直接对照。
2. 按起初空、起初错、起初正确分别统计。看填空何时算对、错数是否原样保留、正确值有没有曾被改坏。对照同图全空运行，列出预填导致的得失。末两轮连续正确与曾经正确分别计数。
3. 检查第一次更新时可用的证据。源节点可从题面取数；其他节点区分父值未齐、父值推出真值、父值推出错数。当后者与该节点初始值也不同时，单列下一轮是否恰好写成这个错数。这样才有机会区分保留旧值与跟随父值。
4. summary.csv 按权重、规模、排列、条件和初始状态汇总，先在同一图内合并三次抽样中的节点机会，再对有该类节点的底图等权。并列底图数与节点抽样次数。原始分层表另含节点类型和父值类别，可复算细分分母。
