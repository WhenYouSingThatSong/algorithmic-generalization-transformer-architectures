# PLAN-008　用手工图复核原始 A′、B、C 的宽图求解与受扰恢复

[计划描述、思路与完成情况](../Research%20Record.md#plan-008)

三张手工图之后补三项同题检验。[宽图与原始 C 的受扰恢复](EXPERIMENT-072/README.md)扩大图形覆盖，比较父值齐备后的求解时间及三个 C 种子的恢复过程。[初始节点值随机预填](EXPERIMENT-073/README.md)在第一次前向前准备好整张图，观察模型怎样处理空位、已有错值和碰巧正确的值。[整图无正确值时的恢复](EXPERIMENT-074/README.md)收紧 073 的条件，排除碰巧正确的初始值，让每个结果格要么留空、要么写着与真值及其父值都不符的数。三项均用原有权重自由续算。
