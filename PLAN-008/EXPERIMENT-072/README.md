# 宽图求解与原始 C 的受扰恢复

沿用 A′ 42（epoch 86）、B 42（epoch 92）、原始 C 42、1234、2026（均为 epoch 143）。入口按已交付的 inline-rebinding 权重清单校验 checkpoint SHA。先在同题全空输入上核对各权重的基础求解表现。

32、64、128 个节点各 12 张模 23 加法图，最长依赖链均为四步，每图保留六个源节点和可追踪的依赖链。同一图按层排列一次，按原始拓扑顺序交错排列一次。比较每个节点父值首次全部正确后下一轮的输出、首次算对时间、首批延迟节点及整图完成时间。规模变化也会改变序列长度及实际层宽，单独改变排列的对照在同一张图内。

每张图按预定编号选择一种排列，在链的中间节点首次算对、整图数值首次全对两个时点分别试验。各模型用自己的起始轮，配对题的同位置供体同步自由续算；记录未达起点和供体不合格。三个分支分别从干净状态继续、换入不同来源但同值的状态、换入指定错值的状态。连续模型换整个节点向量，离散模型只换 VALUE。续算 16 轮，逐轮记录目标、直接子节点和链终点。

从仓库根目录依次运行。默认 checkpoint 位于本仓库的 tmp/runs，可用 `--data-root` 指定实际仓库位置。

交付 tmp/analysis/plan008-exp072/formal 中的五份逐题轨迹、两张宽图表、逐节点表、两张恢复表和固定示例。验收时每份权重应有 72 次干净求解、36 个干预候选图；每个时点均列候选、达到起点、可比较分母。按种子分别报告下一轮回正、同轮干净子节点正确而干预分支跟随特定错值，以及发生该传播且留足末两轮后目标与子节点都持续正确。末两轮正确只描述观察窗口。三个 C 的共同合格集按图号、时点和分支取交集，仍须查看各自实际起始轮。将两种排列视为配对观测。
