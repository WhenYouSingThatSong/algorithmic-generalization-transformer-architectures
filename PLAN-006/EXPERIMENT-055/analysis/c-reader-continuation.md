# 版本取值与修复后的新旧下游

接在[四组机制实验](../2026-11-21/c-research-sequence.md)的分支传播之后。沿用正常窗口、多时点局部纠错、第二层更新监督的 C 种子 42 和 1234，第 50 个后训练周期。两份权重分别报告。这个入口单独记录代码和权重身份，可在上一队列运行期间交接。

## 6．复用的名字指向哪个版本

同一名字先后被赋值三次，每次赋值后都留下一个读取结果，三个读者都加同一个数。模 23 下三次正确答案互异。题目有同名复用和每次使用独立名字两个版本，逐条加法和真值完全相同。六个无关算式放在最后一次读取之后或其前方；三次赋值位置和前两个读者位置相同。间隔与最后读者的绝对位置共同变化。

分别改动只影响第一、第二、第三次赋值的输入常数，另改一个只影响无关算式的常数。比如第三次读取应为 11，第一版对应 5。只改第一版，使 5 变为 8，正确的第三次读取应仍为 11。如果它在原题回答 5，在配对改题回答 8，同时独立命名两题的同位置都答 11，则记录一次**符合第一版的配对响应**。这个现象比单次刚好等于 5 更有区分力，仍属于行为证据。另记录改当前版后是否应变而未变、改较旧或无关输入后是否把原来正确的答案改坏，以及前面的读者是否受后面定义的输入变化影响。

每种子 32 个新题号 × 两种间隔，共 64 个基础条件。每个条件 2 种命名 × 5 个输入，标准求解轮数和额外 4、16 轮分报。版本表保留读者序号、被改版本、正确对照数、可区分旧版的分母和命中数。三个读者与多个时点来自同图，勿当独立图。

## 7．同一上游读回正确后，旧结果和新计算是否一起恢复

在同一题的早期和较晚时点各尝试一次上游向量替换。只有接收端读对四字段、供体符合预期错值和其他三个字段时才注入。从同一快照分干净、受扰两臂继续。选定一个已存在的直接下游；八轮内先要观察到干净下游正确、受扰下游恰好采用错误上游对应的值，再找首次两臂上游数值都读回正确的轮次。传播与上游回正可以发生在同一轮。记录旧下游此时数值是否已经正确。所有未达到条件的尝试单列。

此时向两臂都追加一条算式，操作数、加数与旧下游完全相同，结果写进新变量。比如旧下游因上游从 4 被改作 5 而把“加 9”算成 14；上游又读回 4 后，旧位置能否把 14 改为 13，同时新位置第一次算这道式子能否得到 13？同快照另留一对不追加的臂，测追加本身对旧答案的影响。追加后连续观察四轮，逐轮记录：

- 全部预定尝试、两端资格、是否特异传播、是否在窗内观察到上游回正。
- 在干净臂新旧读者均正确的同题分母上，受扰臂的新旧都对、仅旧对、仅新对、都错；另列该轮两臂上游仍读对时的新旧差异。
- 若干净臂新读者首轮尚不能算出，该题仍留在原始轨迹，首轮不进入上述四格。追加时已恢复／尚未恢复的历史读者分别报告。后一组含所有非正确读出，具体值留在单题文件。
- “回正”以数值为准；一次正确读出和连续稳定修复要分开。新旧读者的存续时间和序列位置不同，较晚出现的新读者得到正确输出能证明该条件下的新计算成功，单凭此结果无法定位内部存储或算法。

每种子两个链长（4、8）×32 题，64 张基础图、128 次预定注入。两种子的正式新题号均为 192–223，小测题号 256。完整单题文件含题面、真值、注入前状态、受损与追加轮次、四条分支的读出。

## 服务器顺序与交付

Agent C 在旧队列 fanout 正式交付后运行本入口。若旧队列正在写入，等原进程结束并核对其 delivery；若旧队列未启动，先按原文档运行 research_queue.py，成功退出后运行以下命令。使用独立工作树时各路径仍指向实际服务器数据。Agent B 复核两表及固定样例的分母。

```bash
ROOT_DATA=/workspace/lab-xj/users/jinxi/code/yhy/algorithmic-generalization-transformer-architectures/tmp/analysis
python tools/c_hard_graphs/reader_queue.py \
  --plan "$ROOT_DATA/c-update-20261119/data/plan.json" \
  --train-root "$ROOT_DATA/c-local-update-normal-v1/train" \
  --out "$ROOT_DATA/c-reader-continuation-v1" --device cuda
```

命令自动依次完成版本实验的小测、正式，以及新旧下游实验的小测、正式。每阶段交 formal/<stage>/summary.csv、delivery.json 和两份模型身份，零分母的比率留空。旧版命中同时给出独立命名对照；新旧读者分别列初始资格、传播、回正和实际可比的图数。每种子每档取最小题号展示轨迹，未入选时展示原因。已有单题文件可续跑。服务器结果及路径回填 board/log。
