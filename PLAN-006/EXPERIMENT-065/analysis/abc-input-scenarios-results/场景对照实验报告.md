# 原始 C 与离散 A′、B 在相同注错场景中的行为

考察普通连续模型 C 在哪些场景可以改写已经算过的结果，以及这项性质在同架构离散 A′ 和带纠错训练的 B 上分别怎样表现。A′、B 为种子 42 的 e86、e92；两个原始 C 为种子 42、1234 的 e143。推断范围限于这些权重与实际合格的题例。

## 已算位置能否重新写对

每项在相同合格题例上比较。对内部节点只改其已算对的值，保留原图与父值。连续模型换对应位置的隐藏向量，离散模型只换数值字段。

- 目标首次算对后改错。下一轮重新算对的次数为离散 A′ 0/137，离散 B 137/137，原始 C（42） 128/137，原始 C（1234） 84/137。在子节点确实采用特定错值且尚有两轮可观察的题例中，末两轮两处均正确为离散 A′ 0/137，离散 B 54/54，原始 C（42） 134/137，原始 C（1234） 132/132。
- 目标与子节点首次均对后改错。下一轮重新算对的次数为离散 A′ 0/123，离散 B 123/123，原始 C（42） 108/123，原始 C（1234） 54/123。在子节点确实采用特定错值且尚有两轮可观察的题例中，末两轮两处均正确为离散 A′ —，离散 B 122/122，原始 C（42） 88/89，原始 C（1234） 37/38。
- 整图首次算完后改错。下一轮重新算对的次数为离散 A′ 0/79，离散 B 79/79，原始 C（42） 70/79，原始 C（1234） 30/79。在子节点确实采用特定错值且尚有两轮可观察的题例中，末两轮两处均正确为离散 A′ —，离散 B 79/79，原始 C（42） 42/42，原始 C（1234） 11/11。

下表逐场景展开。父值干预时，“目标”仍指它的子节点；分层与扩展表固定跟踪链中内部节点及其直接子节点。注入点本身、输入源和输出终点的逐轮轨迹可回到原始记录核对。
