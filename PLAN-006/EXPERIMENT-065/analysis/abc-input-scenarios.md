# 按注错前的图状态构造 A′、B 与原始 C 的对照

研究主题是检验普通连续模型 C 是否已经表现出离散 A′ 在接受纠错训练形成 B 后才观察到的一部分行为。已有 32 个同题例提示，A′ 保留了被改错的内部值，B 和两份原始 C 都曾重新算对。此次先枚举可以实际写入的数据场景，最后按场景报告各种轨迹，包括与这个研究假设相反的结果。

## 数据怎样构造

每个场景先写明原图、起始状态、被改位置、改前值、写入值及其来源、写入几轮。图中的箭头从操作数指向使用它的节点。无父节点的变量叫**输入节点**，有父也有子的叫**内部节点**，没有子节点的叫**输出终点**。写输入节点时改的是已经求出的数值，题面上给它赋值的原始常数仍然可见。

| 注错前可指定的条件 | 本批实际操作 |
|---|---|
| 目标还缺至少一个父值 | 提前把内部节点填对或填错，或者只改更早的祖先，或者给尚空的直接父节点填错值。保存哪些位置原来就是空的 |
| 父值到齐，本轮正要算目标 | 目标仍为空时提前填对、填错或换入空状态。也可保留空目标，只改它这一轮将读取的父值。另有只改已经用过的祖先的分支 |
| 目标刚算对、全图还在求解 | 改目标本身，或只改它的父节点、祖先、另一分支。在实际时点试验中记录直接子节点原来是空、正确还是已有其他值 |
| 目标与直接子节点均已算对 | 改回头还会被引用的内部节点。保留子节点原有答案，并记录整图是否已完成。该条件与整图完成可在部分图上重合 |
| 整图已算完 | 分别改输入节点、内部节点、内部节点的父节点、更早的祖先、输出终点。对内部节点还做一次“把原来的非空数值换成较早的空状态” |
| 同时改多个位置 | 改两条独立分支；改同一内部节点的两个父值，让两个偏差相加或相消；同时改父与目标，让两者互相一致或冲突；同时改目标、父节点和祖先。在相消组中，每个父值都错，按两个新父值计算的和仍正确 |
| 施加干扰的持续时间 | 单次写入后自由运行 16 轮；直接父值另做持续四轮写错、随后自由运行 16 轮，以及同位置同值持续写入。每轮保留实际输入 |
| 对照与自然起点 | 同起点不干预、原样写回、同值不同来源、空位预填正确。未干预轨迹中另记自行产生的数值错误；在同一现场比较自由续算与人工放回先前正确状态 |

“正在算”“已算完”描述注错前的状态。32 题与扩展组按图深度预约时点，逐题核对干净状态中应该为空和应该有值的位置。192 题组直接从各模型实际轨迹找到起点，末端最多搜索到标准轮数再加四轮。统计保留每个模型的实际轮次与未满足条件的图。不同位置上的统计量不能直接互换，例如只改父值的实验中，父节点写入后是什么、目标如何更新、子节点怎样续算应从各自位置读取。

## 三组题与权重

| 题组 | 题例 | 权重与执行 |
|---|---|---|
| 已交付的真实求解时点实验 | 192 张，32／64／128 节点，最大深度独立取 4／10，每格固定 32 图 | A′ s42 e86、B s42 e92 重做全部操作，包括输入节点、内部节点、输出终点、持续写入、自然错误与回放；原始 C s42、s1234 e143 使用已交付的 384 个逐图文件 |
| 原始分层注错实验 | 16 个编号各两种链长，实际 21／29 个节点，32 个题例，每题 22 种操作 | 从原始 C 归档逐条读取原题、位置、供体轮次和操作清单，A′、B 独立续算。原始 C 三种子历史轨迹可追溯，正式四方表使用 42 与 1234 |
| 扩展场景 | 新编号 400–431 各两种链长，共 64 个题例，每题 42 种操作（含干净对照） | 四份权重都运行相同输入。保留每个定义节点的逐轮数值、每次写入前后目标字段以及对应干净分支 |

第一组每图 32、64、128 指实际节点数；后两组的 4、8 指两条链各自长度。分层表把 A′、B 的数值字段改成供体值，C 换同一位置的隐藏向量；终点没有下游，同值替换对离散值等于原样写回。扩展组“两父值相消”的干净真值和改后父值的模加结果可以精确验证。先用以上固定数据跑，轨迹中的其他现象也应记录。

## 远程执行与最终汇报

本轮用户已明确授权 A′、B 执行。Agent B 在固定快照运行 A′、B 的三个题组；Agent C 复用两批历史交付并运行两份原始 C 的新增场景。双方独占各自模型的输出目录，可使用同一输出根。先各自执行带 `--smoke` 的命令，再去掉该参数运行正式数据。

```bash
python tools/c_hard_graphs/abc_scene_queue.py --models A_s42 B_s42 --data-root /path/to/training-worktree --smoke
python tools/c_hard_graphs/abc_scene_queue.py --models C_s42 C_s1234 --data-root /path/to/training-worktree --smoke
```

待两边完成，Agent B 运行以下命令，将真实数据生成的 Markdown、按场景的同题表、逐图基础拟合、自然错误表及可复算的轨迹或其归档交付至协作分支。命令读取全部正式原始文件，缺任一权重或题例会指出该缺口。

```bash
python tools/c_hard_graphs/abc_scene_report.py --out docs/records/2026-11-22/abc-input-scenarios-results
```

最终报告先用日常语言按场景写看到了什么，再列数据。报告入口会从共同合格图中按最小编号取真实轨迹，展示写入后、前三轮及第 16 轮的目标和子值。Agent B 结合轨迹填写观察与例外，核查训练日志、同题干净拟合、两种子差异与末轮干净漂移，具体指出在哪些场景 A′ 也能恢复、B 或 C 未恢复，哪些仍缺样本。原样未改、真正写入数值错误、暂且无值、输出另一数值、自然错误由模型回正、由实验程序干预后回正，各自按轨迹原义报告。归因限于当前受测权重和训练设置。
