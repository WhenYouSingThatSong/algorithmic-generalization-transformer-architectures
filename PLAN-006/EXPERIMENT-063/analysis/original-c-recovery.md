# 原始连续模型 C 受扰后的数值恢复

## 已有证据

两份原始 C 在同一批图上都出现过完整行为链。将已读对的节点换成表示另一个数的向量，直接子节点随后得到该错值对应的答案，继续循环后，两个节点又都正确。这个发现使原始 C 成为估计专门纠错训练增益的必要基线。行为链本身同时容许按父值重算、选择性更新等解释。

| 权重 | 标准轮数下数值正确节点 | 实际写入错值 | 下一轮目标回正 | 子节点曾跟随该错值 | 发生该传播后，末两轮目标与子节点均正确 |
|---|---:|---:|---:|---:|---:|
| 原始 C，种子 42，第 143 epoch | 800/800 | 32/32 | 29/32 | 32/32 | 32/32 |
| 原始 C，种子 1234，第 143 epoch | 800/800 | 32/32 | 17/32 | 32/32 | 32/32 |
| 离散 A′，种子 42，第 86 epoch | 800/800 | 32/32 | 0/32 | 32/32 | 0/32 |
| 离散 B，种子 42，第 92 epoch | 800/800 | 32/32 | 32/32 | 10/32 | 10/10 |

每个模型在同一批 16 个编号（352–367）、两种链长的 32 个题例上各做一次注错。每图指定一个内部节点和一个直接子节点。题例实际为 21 或 29 个节点。标准轮数是图最大依赖深度加一。前四个字段同时正确的节点数，原始 C 两个种子分别为 800 和 799。原始 C 与离散模型分别替换整个目标向量或单个数值字段，两者匹配的是可读语义。表中“曾跟随”要求同一轮未干预分支的子节点正确，干预分支恰好等于把错值代入子节点表达式的结果。最后一列的分母仅含已观察到这种传播且仍有两轮可观察的题例。随访共八轮。

旧实验按图深度预定注错轮次，并核验注入前目标四字段正确。它支持“这个时刻已读对”。是否恰为这份权重**首次**算对，要从它自己的逐轮轨迹判定。旧实验指定目标的自然错误回放样本为零。整图其他位置发生的自然变化另计，不能用人工错的 32/32 估计模型自发出错后的恢复比例。

权重来自固定 32 节点加法任务的 150 epoch 运行，均固定取 e143。SHA-256 前缀依次为 `4a00d6a21a7e`、`0bca3a2b91e8`。来源清单中取的是后训练运行的 **source**，也是旧实验直接载入的原始权重。配置名为 `C0-M4-Nodes32-ADD-L4H16D384-DeBERTa`。四层、16 头、隐藏宽度 384；50,000 张训练图，6 个输入节点，图深度最多 6，每个运算节点 1–3 个父节点，模 23 加法。验证配置为 128 节点。AdamW、学习率 0.001、batch 32，训练循环上限 8，实际轮数随批次深度。每轮用标准分步状态监督各字段，下一轮接收模型自己的隐藏状态。专门纠错训练开关关闭，配置里保留的污染概率未生效。文件名中的损失保留四位小数，精确损失及收敛过程以训练日志为准。[配置](../../../experiments/configs/C0-M4-Nodes32-ADD-L4H16D384-DeBERTa) · [旧基线与按规模分层的拟合](../2026-11-14/c0-capability-report.md) · [权重来源](../2026-11-20/c-update-training-handoff.json) · [逐图结果](attribution/c-attribution/four_conditions/graph-counts.csv)

训练时点须区分。仅在新可算位置训练的离散 B 和相应的连续单时点纠错版本，可以用于研究向其他时点的迁移。原始 C 从未做过这类人为污染训练。多时点且带第二层更新监督的 C 已在刚可算、计算中、整图完成后三类场景受训，应单列其结果。

## 这一批要区分的现象

| 实验 | 具体操作 | 结果能回答的问题 |
|---|---|---|
| 基础求解与状态保持 | 每个模型做同一批干净题，在标准轮、额外 4 轮和额外 16 轮记录节点数值与四字段正确数 | 同一难度下哪些模型已算好；继续循环时已有结果是否漂移 |
| 一次注错 | 改一个输入节点、链中节点或终点。分别从目标首次四字段正确、目标与直接子节点均正确、首次整图数值正确的状态分叉 | 局部回正、沿边传播、传播后持续回正分别发生在哪些时点。子节点已算对只描述其状态，因果使用由受扰与干净轨迹的差异判定 |
| 更新依赖什么 | 对内部节点分别只改目标、只改父值、同时改两者。双改使目标注入值、原答案、按错父值重算的值三者互异 | 父值坏而目标原本正确时，它会不会把对的答案也改坏？两个来源给出不同数字时，输出跟随谁？ |
| 持续错父、随后释放 | 连续四轮只把同一父节点改成预定错值，并设置同一父节点四轮同值替换对照；释放后再看 16 轮 | 目标是否持续跟随父值，父值回正后错误或修正怎样传递 |
| 模型自己犯错 | 干净轨迹里扫描所有到达应算轮、上一轮四字段正确、本轮读出另一个数字的节点。对有直接子节点、变量身份仍正确且其余父值正确的事件，按固定顺序每图最多回放四条边 | 比较保留自然错误与放回上轮正确状态时子节点的输出。分别报告候选节点、子边、实际回放、特异挽救。回放整段隐藏向量同时携带上一轮的其他信息 |

每格固定 32 张新图，节点数取 32、64、128，最大深度独立取 4、10，共 192 个题例。图中保留一条可追踪的依赖链，与随机背景表达式交错，同一题的四个模型共用变量名、图、替代数值及干预位置。它是用于机制比较的受控图族，与原训练集的拓扑分布有区别。每次干预并排运行同起点的未干预分支。更换向量的同值对照从同题的另一输入版本取同位置状态；输出同时记录实际差向量长度。差为零计作原样操作。离散模型只换数值，同值操作必然原样。终点无子节点，下游指标留作不适用。

每个角色、时点、权重分别记录候选与合格数，首次整图完成最多搜索到标准轮加四。即使找不到合格起点，这张图仍进入基础能力表。普通单次注错观察 16 轮。自然事件在整个干净观察窗内计数，包含外推轮次，逐事件存绝对轮次，汇报时区分训练深度内、外。四模型比较同时给出各自合格、四方共同合格、四方在同一绝对轮合格的计数；概率分别用实际注入、干净子节点有机会答对、已传播且有后续观察作分母。报告保留配对题号，不把同图不同轮次当独立样本。
