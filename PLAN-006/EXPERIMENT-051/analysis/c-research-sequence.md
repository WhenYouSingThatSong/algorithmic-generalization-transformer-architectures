# 停止更新之后的四组机制评测

本轮沿用 C（多时点局部纠错、第二层更新监督，正常窗口），种子 42、1234，第 50 个后训练周期。依据[上轮难图结果](c-hard-graphs-results.md)，同名复用会降低正确率，追加循环可使身份读出漂移，上游读回正确与下游出现错值可以发生在同一条轨迹上。两份模型的[末周期联合训练损失](c-local-update-fit-history.md)分别为 0.1941、0.2906。所有主表按权重、图形和难度分别交付。整个队列是推理和分析，研究问题编号沿用[研究清单](research-checklist.md)。

### 解释边界

1. 首次算对与修回分别按“历史上是否曾正确”和“上一轮是错数还是空值”计数，这两个维度会相交。每个窗口的末轮正确位置数减首轮正确位置数，等于进入正确的次数减离开正确的次数。首次输出单列。数值读出连续正确不等于下游始终用对它。
2. 置信指标为数值读出头第一与第二候选的 logit 差，包含空值等候选；固定分档为小于 1、1 至小于 4、至少 4。连续读数只比较 VALUE。第 t 轮的置信与重复信息在第 t+1 轮开始前可用；更新信号最早在第 t+1 轮第二层可用，不能用它声称整轮计算均可节省。这项是前瞻关联测量，操作门控的因果效果由步骤 0 单独报告。
3. 身份实验在标准求解轮数和其后第 8 轮各取一次快照。身份供体来自同题全局交换两个名字的版本，移入的仅是目标定义位置；原题其余隐藏行保留。另设交换无关名字的供体，监测换源本身的影响。随后拼接两个新算式的初始向量。举例，若两节点值为 4 和 9，同加 3 应读出 7 和 12；若干净读者正确，而替换后引用第一个名字的读者读出 12，计一次符合混淆方向的错误。两个值相同时这种错读无法区分，只报告正确和损伤。供体整向量还可能携带其他信息。自然身份读错的起点单独留在明细中，人工干预的结果不能直接解释所有自然漂移。
4. 分支实验只改变哪个上游进入固定的四个加法。在上游结构上刚可算、标准求解轮数后第 4 轮各注错一次。供体值偏移为非零 δ，干净预期最终值为 y，错值完全传过 k 条分支时应为 (y+kδ) mod 23。每个汇合位置也按实际受影响的父路径数计算预期。相同快照的干净臂作对照。每个受理事件观察 8 轮，累计损伤只对同轮干净正确的节点计数。联合配对表的分母是同一权重、同一时点在全部三个分支数下都受理的图。门槛为接收端和供体四字段通过；覆盖不足时同时报告尝试和拒绝。
5. 两个种子分表。按干净能力、拟合和实际受理数解释差异。此队列可以说明这两份权重怎样计算和传播错值；纠错训练本身的增益需要另配同起点对照。

## 服务器交接

Agent C 为唯一队列执行者；Agent B 在每阶段交付后复核分母。先确认前一批停止更新任务是否有进程在写。如果有，保留该进程，等其所属任务结束后再接入同一路径；如果尚未启动，可直接从下面的队列入口开始。只开一份队列，固定一张可用 GPU，两个种子逐个跑。各阶段先小测、再正式、再进入下一阶段。已完成的停止更新推理直接复用回执，新阶段支持按题恢复。

仓库根目录按服务器实际路径设置变量。旧难图原始轨迹在第一条路径的 formal 子目录下；停止小试目录须指向原输出根。训练权重目录下应有 C_s42/final.ckpt 和 C_s1234/final.ckpt。

```bash
ROOT_DATA=/workspace/lab-xj/users/jinxi/code/yhy/algorithmic-generalization-transformer-architectures/tmp/analysis

```

每个新增阶段交 `formal/<stage>/summary.csv`、`contrasts.csv` 和 `delivery.json`，分支阶段另交 `paired-fanout.csv`。置信表与身份表保留空分母，比率留白。对未观察到的置信组合，结合暴露明细标为无观测；切勿补为零成功率。身份实验的条件表逐臂报告，四臂共同合格的行用于主比较；多轮读出共享同一注入，汇报时分别列出，不将四轮相加当成四次注错。分支实验中 step=0 是尝试清单，step=1–8 是节点观察。交一张实测题的逐轮例子并注明取样规则（例如每档最小题号），原始轨迹留服务器，更新 board/log 后推回 reproduction。
