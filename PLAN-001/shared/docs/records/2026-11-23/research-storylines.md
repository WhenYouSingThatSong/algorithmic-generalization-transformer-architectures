# 循环推理如何修订已有计算？五条研究主线

2026 年 11 月 23 日 · 研究路线与实验决策

## Brief

**循环让一个已经给出答案的位置仍有机会改变。我们想解释，模型怎样修订错误的中间结果，同时保住已经做对的计算。** 这个问题可以在相同的题、相同的位置、相同的起始状态上研究：改动一次，允许模型继续循环，观察它用什么证据更新、哪些下游受到影响，以及最终答案是否因此改善。

已有实验给出了研究起点。在测过的内部节点上，离散 A′ 会保留已填的错数，清空后却能重新填对；经过纠错训练的离散 B 和未经专门纠错训练的原始连续 C 都能改写已有数值。有时，目标已经回正，原先正确的子节点却刚按旧错值更新。在一批较晚时点的同题干预中，纠错后训练 C 比原始 C 更常立即修回目标，下游也更常采用注入的错值。**允许改写既带来修复机会，也可能扩大短暂扰动的代价。** [四模型逐轮对照](../2026-11-22/abc-input-scenarios-results/原始C与离散模型的场景对照简报.md) · [后训练同题比较](../2026-11-22/c-attribution-delivery.md)

五条主线围绕同一问题展开。候选一研究**发生冲突时该改哪一方**；候选二、三分别追查目标向量和周围状态；候选四检验结论能否推广到已有下游依赖的计算；候选五把机制发现用于**测试时计算分配**。前四项即使得到“持续重算就足以解释”的结果，也能说明这种更新规则在什么条件下有效、又会在哪里失效。

## 共同实验基础

任务沿用 *Unlocking* 工作中的模加法计算图。主比较有两个轴：每轮传递离散字段或连续隐藏向量，以及是否引入仅在新可算位置施加污染的纠错训练。离散侧比较 A′ 与 B，连续侧在同一种子内比较原始 C 与只在新可算位置训练纠错的 C。**多时点纠错、第二层带更新位置监督的 C** 单列，用于研究显式检错与实际修改的关系。连续侧使用种子 42、1234，离散侧本轮使用种子 42。

先按输入条件造题：何时干预、改哪个位置、父节点和子节点当时是否已经算对、错值维持多久。再根据实际轨迹判断发生了重算、传播、恢复或停滞。各模型保留未干预的同题分支。比较训练方式时同时查看各自的训练曲线、末期损失和同题干净拟合，按种子报告；不同目标函数的损失只在各自配方内解释。四组都是循环模型，若要主张循环相对普通架构的优势，还需匹配基础拟合并做计算量、参数量对照。[现有实验设计与覆盖](../2026-11-22/abc-input-scenarios.md)

## 候选一｜纠错训练改变了模型对已有答案的信任程度吗？

**现象与假设。** 子节点已有答案，当前父值却推出另一个数。冲突至少有两种成因：子节点错了，需要重算；父节点暂时错了，子节点原来的答案值得保留。已有结果与一个简单假设相容：纠错训练提高了已填位置依据当前父值重新计算的倾向。这个变化可以同时解释目标修得快、健康下游也容易跟着改。

**决定性对照。** 构造“父对、子错”和“父错、子对”的镜像题。使局部可见的父值、子值、位置和时点匹配，把能判断真值的证据留在更远祖先或原题中。先看模型改哪一方，再短时屏蔽或替换这条证据，以无关位置干预作对照。另在父子原本一致的健康位置做同样的父值读取干预，以本轮首次计算的位置验证该干预有效。

**结果导向。** 两类冲突都跟随父值，且健康位置也依赖相同通路，支持持续重算。若模型能在两题中作出相反的正确选择，移除远端证据后选择性又消失，就有证据定位它依据什么判断哪一方有错。由此可设计同时包含两类冲突的训练，以“应改时修对、应留时保住”检验改进。[第一批](first-batch.md)先测修回与传播的双向代价；镜像题和通路干预是后续实验。

## 候选二｜数值已读对的隐藏状态，是否已经恢复到可供下游使用？

**现象与假设。** 目标回正的同一轮，子节点仍可能读到此前受扰的状态；同步更新本身就能产生这个现象。更强的假设是，目标读数已相同，连续向量仍携带影响后续计算的历史。要检验它，得换一个此前没有机会接触错误的读者。

**决定性对照。** 在同一位置、同一绝对轮次取得三种向量：稳定正确、刚从空位算对、刚从错误中恢复。匹配目标的数值、变量身份等读出，把向量分别放进同一上下文，让新追加的子节点首次取值。保留原样写回和确切错值对照，确认这个新子节点确实会使用所换入的信息。

**结果导向。** 若新子节点随向量历史给出不同答案，优先寻找能定向改变下游计算、同时保持目标数值读出相同的内部成分。若新子节点正常而旧子节点仍错，优先追查旧子节点保留的计算历史。前一种结果支持用“恢复后的状态能被正确使用”设计后训练；后一种结果指向修复下游。第一批已实现同值异历史与新读者实验。

## 候选三｜为什么单点人工错误容易消退，自然形成的错误却能维持？

**现象与假设。** 人工注错通常从原本正确的状态出发，周围仍有可靠证据。原始 C 自然运行时，已观察到错值被子节点实际采用、回放先前正确状态又能救回子节点的轨迹。在这批可回放且有后续观察的边上，自由续算没有达到上下游连续两轮同时正确。差异可能来自目标向量本身，也可能来自周围节点已经形成了相互支持的错误状态。

**决定性对照。** 固定同一图、位置、轮次与错误数字，交叉改变目标向量的来源和周围状态。目标使用自然错向量、人工同错数向量或此前正确向量；周围保留原样、只恢复错父节点、或恢复其他已到求解轮次的错误位置。逐题记录哪些位置真正发生了替换。

**结果导向。** 仅换目标就改变下游，说明目标的编码方式有作用；两类错向量都要等特定父节点恢复后才能修回，则支持上下文证据不足的解释。两种因素也可能相互作用。第一批已实现交叉回放。解读时区分全部自然错误、可回放边和成功配到同错数供体的事件。

## 候选四｜只在新可算位置训练，为何能修复已经被使用的结果？

**现象与假设。** B 和只在新可算位置训练纠错的 C，都在更晚的已算位置表现出回正。“更晚”包含三个不同变化：经过的轮数更多、位置已经有值、这个值已经被其他节点使用。尤其对连续模型，结构上刚可算时就可能读出数字，需记录实际受扰状态。

**决定性对照。** 改同一个内部节点，分别安排它刚可算、刚算对但尚无人使用、已被一个或多个子节点使用、整图已完成。进一步构造同一轮次的配对题，使目标已正确的时间相近，只改变是否已有下游采用它。分别追踪目标修回、旧下游修回、新下游首次使用和指定输出受损。

**结果导向。** 如果目标修复跨时点保持，而历史下游的恢复随使用范围扩大而恶化，就能给泛化划出具体边界。若指定输出也能随历史修订稳定恢复，才有依据把收益推广到持续推理。第一批覆盖多时点和不同分支数；“正确了多久”与“是否已被使用”完全独立变化的配对仍需补做。

## 候选五｜测试时自适应计算：每个位置能否自行决定继续算、暂存或重新参与？

**研究动机。** 同一张图里，深分支可能还需要额外计算，浅分支已得出可靠结果，另一个旧位置又因上游修订而需要重算。整图统一多转一轮，会把预算同时花在这三类位置。方案二要检验的是：**同样的测试时计算预算，由模型逐位置分配，能否完成更多必要计算、修复更多真实错误，并保住已经有效的结果？**

**架构设想。** 仍输入整张模运算图，沿用相近规模的共享循环块。每轮结束，模型利用当前位置状态及其依赖信息，决定该位置是否进入下一轮前向。暂存的位置保留当前表示，其他活动位置仍可读取它；若后来上游有新证据，该位置可以再次参与更新。这样就能比较“整图统一转多少轮”“每张图自行决定何时停”“同一图里各位置转不同轮数”。当前多时点 C 的第二层更新标记只提供过程监督，所有位置仍完成前向；它可作为预测信号的参照。方案二的主要设计是让选择**实际改变执行和成本**，并允许从任务目标与计算代价学习选择，人工更新标签可作消融。

**先用现有权重验证预算分配的价值。** 在同一张有长短分支、已有正确结果和局部错误的图上，从同一状态分叉。比较整图继续、暂存已解位置、暂存后允许因上游变化重新参与。观察额外更新究竟完成了新计算、修复了曾被使用的错值，还是损伤了原本正确的位置。用真值选位置只估计可获得的收益上界；另行检验置信度、父子冲突、第二层标记等推理时可得信号，能否预报多算一轮的收益。

**再做可学习的调度。** 若不同位置确实从额外计算中获得不同收益，且可用信号能预测这种差别，再训练逐位置选择器。模型从训练早期就接触干净题和受扰题，学习在答案损失、修复收益与计算成本之间取舍。保留永久停止和可重新参与两个版本，直接检验为已停位置保留修订机会是否值得。与固定全图循环、整图自适应停止在相近参数规模和基础拟合下比较，报告**等预算的输出正确性、等正确性的实际耗时**，并计入选择器、读取暂存位置和稀疏调度的开销。只跳过状态写回仍可能执行全部计算，此类模拟只用于行为分析。

**推进条件。** 第一批的分支传播与标记分析能指出哪些位置值得继续研究；专门的预算分叉实验和架构训练另立批次。如果逐位置选择的理想上界也接近统一循环，研究仍然能说明额外循环主要用在哪里，同时可把精力留在前四条机制主线上。[既有方案二研究清单](../2026-11-21/research-checklist.md)

| 顺序 | 回看什么证据 | 结果怎样改变下一步 |
|---|---|---|
| 现在 · 完成第一批 | 八份权重的同题评测、原始 C 自然错回放、同值向量与新读者、不同分支数的传播代价、多时点 C 的第二层标记 | 两个执行者沿现有看板交付，按种子、同题拟合与真实入选分母汇总。[第一批协议与验收](first-batch.md) |
| 结果回来 · 确定机制重点 | ① 新读者是否受向量历史影响？② 自然错的恢复更依赖改目标还是改周围？③ 训练是否同时加快局部修回并增加下游损伤？ | ① 决定优先研究目标表示还是旧下游；② 决定先干预哪条信息来源；③ 决定是否优先构造“父对、子错／父错、子对”的镜像题。可并行追查有证据的解释。 |
| 有因果证据后 · 检验改进 | 在新留出的题、不同依赖深度和使用范围上，检验机制预言；再做一项有针对性的训练或架构改动 | 按发现选择训练可靠性判断、恢复可用向量、修订历史下游，或进入候选五的预算分配实验。保留无差异和反向结果，沿用同一套干净与受扰对照。 |
