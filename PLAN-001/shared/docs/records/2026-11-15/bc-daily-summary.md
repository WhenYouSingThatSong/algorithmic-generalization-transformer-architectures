# B、C 今日实验汇总：做了什么，结果说明什么

日期：2026年11月15日。覆盖今天已完成、已核对的实验与补交数据，截至审阅提交 `6b765c9`。昨天的[实验简报](bc-experiments-brief.md)保留不改。

**今天最主要的进展：B 的修错能力扩展到了多父节点和多种错值，但仍发现持续失败；C 已完成长程保持与两种注错后训练小试。长程保持有明确改善，语义注错能减轻部分错误传播，却没有显示更快恢复。强噪声进一步暴露了“目标读出正确、下游计算仍受影响”的能力缺口。**

## 1. 任务、权重和指标

任务是一组有依赖关系的加法方程，结果取模23。模型每轮处理整道题，反复更新各位置的状态。父节点是当前方程引用的变量，下游是直接或间接依赖它的节点。

| 权重 | 今天用来做什么 |
|---|---|
| A′：离散、无专门纠错训练，s42/e86 | 与B对照，看模型会不会更新已经填上的错值 |
| B：离散、有纠错训练，s42/e92 | 多父节点、多错值及异常案例分析；今天没有重训B |
| 原C0：连续模型，s42/e143、s1234/e143 | 同值/异值向量替换、不同时点干预、自然错误的局部修复 |
| 原C0：s2026/e143 | 补充基础能力数据，并作为今天两批后训练的共同起点 |
| 第一批后训练：普通续训、额外D轮、额外2D轮 | 比较延长训练中的计算/保持时间是否有效 |
| 第二批后训练：hold、noise、semantic，均为新训练第3遍结束的权重 | 分别为只做保持、保持时加随机扰动、保持时换入语义错误向量；比较额外注错收益 |

s是随机种子，e是原训练周期。以上模型主体都是4层、16头、隐藏维度384。C0使用原32节点、深度≤6的训练配置；今天的后训练从现有权重开始，不是从头训练。后训练只用了s2026，不能称为三种子复现。

**两条线的操作不同：**B把解码出的离散字段传到下一轮，可以精确改一个数值；C传递完整隐藏向量，读出的数值和变量名只用于观察。C实验改的是向量，不是把解码数字直接写回。

核心指标为节点的**数值正确率**、**四属性同时正确率**（语法类型、变量名、运算类型、数值），排除常数和填充位置。一般采用逐图等权，同时保留原始计数；整图全对、传播与恢复作为补充。下文“末两轮正确”仅指观察窗口最后两轮，不表示永久稳定。

## 2. B：已有答案能否更新，是否受父节点数和错值影响

先在56张合格图、每时点92个单父节点目标上试验，再扩展到固定64张图，每图各选一个有1/2/3个父节点的目标，共192个目标。分别在“目标刚算对”和“整图数值都算对”两个时点操作，随后观察16轮。

| 实验具体行为 | 结果 | 能说明什么 |
|---|---|---|
| 把已经算对的目标清空；父节点不改 | 扩展样本中，A′、B两时点都在下一轮恢复192/192 | A′仍能计算空位置，不能把它描述为完全不会重算 |
| 把目标改成错误数字；大部分目标测试+1/+3/+7/+11，小部分枚举全部22种错值 | 合计2400个“目标×时点×错值”观察，A′首轮及末两轮正确均0，B均2400 | B通常能更新已有错值；A′在这些样本中保留已有错值。2400不是独立图数 |
| 同时看目标的下游 | B的+11条件每个时点仍有35/795个下游节点观察未在末两轮恢复，尽管目标192/192首轮已修回 | 目标修回，不等于整条计算链修好 |
| 对以前的失败节点，从干净状态开始枚举错值 | 正确值是2。B写入其它21种错值最终回2，唯独写8后第1–16轮持续为8；父输入始终为10、5、10 | 失败不是必须经过旧污染过程才出现；至少这个节点对不同错值的行为不同 |

最后一例的正确计算是 `(10+5+10) mod23=2`。写8后不恢复，不能用“父节点一直错”解释；但目前也不足以证明某种固定点或错误检测算法。

另一个时点差异值得保留：A′在目标刚算对时被改错，错误会传给尚在计算的下游；整图已经完成后，同样改目标，下游反而保留已有正确答案。**下游没变错有时只是保留了旧答案，不能自动解释为会纠错。**

来源：[单父节点试验](b-value-update.md)、[多父节点试验](b-multiparent.md)、[已核对的解释边界](../../../ai-collab/handoff/2026-11-15-1636-bc-results-review.md)。

## 3. C：先验证怎样改向量，再看自然错误能否修复

这些实验使用s42/e143、s1234/e143，没有训练新权重。

| 实验具体行为 | 主要结果 | 解释 |
|---|---|---|
| 在同一张图的不同常数版本中取得向量：一类让目标值不变，一类让目标值增加1或3；只把目标位置的向量换入原题 | 371个合格目标、683个直接子节点观察。同值来源下首轮680/683仍正确；异值来源下均0/683正确，其中+1有678/683、+3有682/683符合错父值代入后的预期 | 替换确实能产生特定计算影响；同值来源更换通常不产生这种影响。不是只测4→5，目标原值覆盖0–22 |
| 对同一批目标，在刚算出、整图算完、算完再运行16轮三个时点做相同替换 | 共同169目标、287个子节点。+1替换首轮命中特定错误结果分别285、114、42；仍正确分别0、69、110 | 早期的数值传播最清楚；晚期少命中特定错值不等于没受影响，晚期仍有177/287出错 |
| 找模型自己运行后出现的错误，把目标、直接父节点、或两者的向量换回同题以前的正确状态 | 57个诊断事件。下一轮目标数值正确：不改12、只换目标20、只换父节点15、一起换29；最后两轮各分支都25/57 | 联合替换短期更有效，但没有得到末端净收益；不是纠错训练结果，也不能据此判定未来C+无效 |

向量替换的构造示意：原题`u=4，q=u+9=13`；从另一常数版本取得读出5的u向量，只替换u，再观察q是否读出14。同值对照则换入另一来源、仍读出4的向量。这里比较完整向量，不代表只修改了向量中的独立“数值字段”。

自然错误的57例中，45例数值出错、12例只有变量名出错而数值本来正确。联合替换的首轮增量全部来自其中一类22例：0→17；另一类23例仍0。分类依据是错误发生前一轮的父读出，不是替换瞬间的父状态。末端总数相等也不代表逐例相同：联合替换有1例改善、1例恶化。

来源：[来源对照](c-source-control.md)、[不同时点](c-stages.md)、[自然错误局部修复](c-local-repair.md)、[目标和父节点联合修复](c-joint-repair.md)。

## 4. C：长程保持训练确实有用，但没有解决全部漂移

### 4.1 s2026具备基本求解能力，问题集中在继续运行之后

今天补入的s2026/e143数据中，六档共384张图有383张曾达到整图数值全对；第16轮各档整图正确率为98.4%–100%。但继续到第64轮，两个128节点档的整图数值全对率均为0。**不能把后期低分理解为一开始就不会算。** [基础能力补充](c0-capability-s2026.md)

### 4.2 第一批：把训练中的保持时间延长

令D为图的最大依赖深度+1。使用新生成的1024张32节点训练图和128张验证图，从同一个s2026/e143出发：普通组每图运行D轮；另两组运行2D、3D轮。额外轮次仍监督正确答案，隐藏状态不中断、不回灌正确状态，也不人工注错。

下表使用总循环计算代理量匹配的检查点；到每图D+64轮评估：

| 权重 | 节点数值正确率 | 节点四属性同时正确率 |
|---|---:|---:|
| 原s2026/e143 | 91.43% | 2.93% |
| 普通续训，每图D轮 | 88.62% | 3.32% |
| 额外D轮保持监督，总2D轮 | **99.80%** | **41.85%** |
| 额外2D轮保持监督，总3D轮 | **99.85%** | **46.63%** |

三组分别训练新数据6/3/2遍，循环计算量匹配，优化器更新次数不相同；另做的相同曝光对照也支持长程组改善。因此这是训练配方的收益，不能单独归因于某一个因素。额外2D并非在所有数据档、所有指标都优于额外D。

数值失稳明显减少，但所有组的128张图仍都出现过四属性失稳，D+64时没有一张整图四属性全对。**改善更像延缓、减少漂移，尚不能区分是避免出错还是不断内部修复。** [长程小比较](c-long-pilot.md)

## 5. C：加入注错训练后，比只保持多了什么

第二批重新从原s2026/e143出发，复用上述1024/128图，三组均训练3遍、每图2D轮、393次优化更新：

- **hold**：只进行长程保持训练。
- **noise**：保持阶段约一半图次，在一个内部节点加一次随机方向扰动，长度匹配对应语义替换的向量差。
- **semantic**：在相同计划的位置和时点，换入当前模型产生的异值来源向量，数值偏移覆盖1–22。

这三份权重不是上一节额外D/2D试验的同一份权重。两批训练随机安排不同，评估数据和批处理也有差别，下面的百分比不能与上一表直接排名。

### 正常求解后的保持：六档统一评估

四权重在32/64/128节点×浅/深六档各64图上运行到每图D+64，逐图平均后再六档等权：

| 权重 | 节点数值正确率 | 节点四属性同时正确率 |
|---|---:|---:|
| 原C0 | 79.60% | 2.19% |
| hold | **97.72%** | **34.45%** |
| noise | 96.84% | 27.65% |
| semantic | 96.79% | 34.30% |

D轮时四模型都接近满分；主要差异发生在额外循环之后。语法、运算字段保持正确，四属性失分主要来自变量名，并伴随数值错误。**目前没有看到注错训练进一步提高总体长期准确率；单纯保持已是很强的对照。**

### 只改父节点、只改子节点、同时改两者

128图、两个固定时点，单次向量替换后运行16轮，配不改动、原样写回和同值来源对照。保持时点，第一轮子节点正确数如下：

| 操作 | hold | semantic |
|---|---:|---:|
| 只改父节点u，子节点q原本正确 | 12/128 | **34/128** |
| 只改子节点q，父节点u正确 | **112/128** | 97/128 |
| u、q一起改错 | 0/128 | 0/128 |

**semantic更能减少部分传播，但被直接改错的q恢复更慢。** 只改q时，连原C0在内的四模型第二轮都达到128/128正确；不能把“能恢复”本身当成本次训练才产生的能力。此前逐题联合表也确认，确有目标仍读错、semantic下游却比hold少受损的同题案例。

来源：[三组注错后训练](c-corruption-pilot.md)、[统一基础与父子两点评估](c-basic-evaluation.md)。

## 6. C：持续错父与强噪声，暴露了新的恢复空间

### 6.1 每轮都把父节点改错，持续2或4轮后释放

使用上述四权重、128张图。每个强制轮都写入该绝对时点的错值来源向量；子节点要么保持原状态，要么仅在开始时也改错一次。停止人为覆盖后，再运行16轮。

保持时点、连续改父节点2轮、子节点原本正确：

| 时刻 | hold：q正确 | semantic：q正确 |
|---|---:|---:|
| 第一次强制后 | 12/128 | 34/128 |
| 第二次强制后 | **0/128** | **0/128** |
| 释放后第1轮 | 60/128 | 39/128 |
| 释放后第2轮 | 121/128 | 117/128 |
| 释放后第4轮 | 124/128 | 124/128 |
| 释放后第16轮 | 128/128 | 128/128 |

连续4轮方向相同。**单次干预后的保护不能持续抵抗坏输入，semantic释放后也不更快。** 强制期间u的输出经常已正确、q仍错误，但下一次输入会再次把u改错；这个现象本身不能证明独立信息通道。

### 6.2 提高随机噪声强度，同时看即时和后续损伤

固定前64图、每图两个随机方向，各方向在不同强度间复用。下面是hold权重、保持时点，注入后新增目标数值错误：

| 注入 | 新增数值错误 |
|---|---:|
| 语义错值向量 | 64/64 |
| 同距离的1倍随机噪声 | 1/128 |
| 2倍 | 17/128 |
| 3倍 | 50/128 |
| 4倍 | 73/128 |
| 6倍 | 98/128 |

噪声128试次=64图×两方向，不是128张独立图。此前noise训练1481次原本正确的注入中，也只有24次产生新增数值读出错误。**等向量距离不是等错误剂量。** 强噪声还会制造非数字和其他属性错误，不能只看数值错误率。

再看选中的子节点，保持时点首轮与第16轮正确率：

| 注入 | hold：首轮→第16轮 | semantic：首轮→第16轮 |
|---|---:|---:|
| 语义错值向量 | 6.3%→100% | 23.4%→100% |
| 3倍噪声 | 72.7%→93.8% | 84.4%→95.3% |
| 6倍噪声 | 70.3%→70.3% | 82.8%→74.2% |

语义错误容易在首轮传播，但通常能恢复；**强噪声首轮传播较少，却可能延迟发作、持续残留**。semantic在部分强噪声条件下损伤较少，这是值得保留的迁移观察，但并非所有条件的累计损伤都更低。

### 一个真实案例：目标始终读对，下游仍然出错

s2026派生的semantic权重，晚期时点，原题局部为`u=1，q=21+u=22`。只对u加一次3倍噪声：

| 时刻 | u读出 | q读出 |
|---|---:|---:|
| 注入后 | 1 | 22 |
| 第1轮 | 1 | 22 |
| 第2–4轮 | 1 | **16** |
| 第5轮起 | 1 | 22 |

u的数值读出始终正确，q却出现延迟错误。同图6倍噪声下，u首轮输出已回到1，q从第2轮到第16轮一直为21。**只看目标数值是否正确，会漏掉计算损伤。** 尚不能确定影响保存在目标向量、其它父节点、子节点状态还是结构字段中。

来源：[持续错父与噪声校准](c-stress.md)、[本轮审阅](../../../ai-collab/handoff/2026-11-15-2132-c-stress-review.md)。

## 7. 今天可以保留的结论，以及尚未完成的事

1. **B确有更新已有错值的能力，但不是任意状态都能修好。** 多父节点主样本有效，同时有特定错值和下游持续失败的反例。
2. **C的正常求解能力与长时间保持能力明显不同。** 增加保持监督有效，但变量身份等属性仍会漂移。
3. **保持正确答案、修回目标、恢复下游是不同能力。** semantic减少部分传播，不等于恢复更快或总体更好。
4. **强噪声找到了比单次语义替换更难恢复的一类损伤。** 后续C+应同时看目标、受影响下游和干净题能力，不能只优化目标读出。
5. **今天已有后训练小试，但还没有正式三种子C+结论，也没有确定内部检测/修复算法。** 大部分数据已反复用于开发诊断；独立最终测试尚未开展。

后续候选是：利用现有轨迹统计“目标读对但下游受损”的普遍程度；讨论2–3倍中等噪声的小规模后训练，6倍先保留压力测试；再决定是否扩大到三种子。**这些是待讨论方向，不是今天已经执行的实验。**
