## 任务与评估口径

每道题是一张有向无环计算图。给定叶子节点的数值后，单父节点复制父值，多父节点把父值相加再取模 23。模型反复应用同一个 Transformer 块，每一轮可以并行处理多个已具备父值的节点。

用一张四节点小图说明。题面给出 `18 = a`、`9 = b`、`a + b = u`、`u + b = v`。预期第一轮把 18 和 9 填到叶子的变量字段，第二轮算出 `u = 4`，第三轮算出 `v = 13`。这张图的最长依赖链有两条边，所以按数据文件的口径，深度为 2。叶子计为深度 0，从所有变量值为空开始，仍需要一轮把给定数值写入叶子变量。

| 口径 | 每轮输入 | 分数的含义 |
|---|---|---|
| 教师状态单步（TF） | 正确的当轮输入状态 | 报告中的“新可算节点 VALUE 正确率”只统计本轮新可求值的节点 |
| 自由续算 raw | 上一轮输出的全部六个因子 | 测量公开评估代码回灌全部因子时的表现 |
| 自由续算 clean | 同样回灌上一轮预测，先将 REGRET 和 MODIFICATION 置回 `FALSE` | 测量关闭两个辅助因子回灌影响后的表现 |

假设模型第二轮把 `u` 算成 5，自由续算第三轮会收到这个 5，可能接着算出 `v = 14`。教师状态单步第三轮直接给它正确的 `u = 4`，可以单独看它是否会算 `v`。raw 和 clean 都让模型使用自己的数值预测。两者只改变辅助字段，四个主要因子 SYNTAX、VARIABLE、OPERATION、VALUE 的预测继续原样回灌。

下文的整题分数采用脚本的严格口径。所有非填充位置的四个主要因子都与最终标签一致，才记为一题答对。论文任务定义按所有节点值正确计分，两者在比较原论文数字时应分别标明。两个辅助输出头的损失权重为零，但回灌时它们的值会进入输入嵌入，因此可以影响下一轮。

## 阶段结论

1. **raw 和 clean 对 A 的测得成绩影响很大。** 同一权重、同一数据、同一计分，只切换辅助因子的回灌方式，A-42 best 在 N=128 就从 0/1,024 升至 1,023/1,024。raw对B也有影响，但是目前缺少多种子复现。
2. **A 和 B 的模型结构不一致。** （来自论文附录）当前 A 为 L2H16D256，B 为 L4H16D384。每轮 Transformer 的层数和隐藏维度都不同，比较结果包含结构差异。
3. **目前无法明确自纠错训练的收益体现在哪里。** 现有结果还无法分离纠错训练对干净输入准确率、抗扰能力和错误恢复率各自的贡献。

### 快慢训练路径的影响

自训 A 走慢路径，作者的 A-demo、B 和 A-L4fast 走 fast 路径。离散模型的 `training_step` 同时检查 `use_teacher_pred_for_next_loop` 和 `use_fast_batch_forward`，两者都为真才进入 fast。自训 A 虽然走慢路径，也使用正确的教师状态作为每轮输入。 [训练分支](https://github.com/Awni00/algorithmic-generalization-transformer-architectures/blob/52dd950dce8d32a8e72513999cac5a310e01ca53/experiments/model.py#L332-L344)

| 影响 | 慢路径 `compute_batch_loss` | fast 路径 `compute_batch_loss_fast` |
|---|---|---|
| 前向和反向 | 逐轮前向，每轮按六个因子分别调用反向传播，再累积梯度 | 把各轮的教师输入展平并入同一个 batch，一次前向和一次反向 |
| 损失权重 | 各轮损失求和，首轮 VALUE 损失额外乘 2 | 在轮次、样本和位置上取均值，首轮 VALUE 使用普通权重 |
| 训练轮数 | 按 batch 最大图深度加 1，并受 `max_train_loop` 限制 | 按 batch 最大图深度加 1，当前实现没有应用这个限制 |
| VALUE 扰动 | 启用时抛出 `NotImplementedError` | 支持扰动教师输入，仍以干净的下一状态为标签 |

以当前训练集为例，若一个 batch 有 32 张图、最大深度为 6，两条路径都处理 7 轮的教师输入，也都只更新一次参数。慢路径发起 7 次前向和 42 次反向调用，后者包含零权重辅助因子的调用。fast 一次处理 224 个“图 × 轮次”输入，减少调用开销，也扩大单次前向的激活规模。当前训练上限是 8 轮，因此这个上限在深度不超过 6 的训练集上没有截掉任何一轮。归档日志标为 Epoch 10 的进度行里，A-1234 slow 用时约 7 分钟，B fast 约 3 分 42 秒。这两次运行使用不同 GPU、架构与扰动设置，同条件下的加速倍数仍需单独测量。 [fast 实现](https://github.com/Awni00/algorithmic-generalization-transformer-architectures/blob/52dd950dce8d32a8e72513999cac5a310e01ca53/experiments/model.py#L503-L605) · [慢路径实现](https://github.com/Awni00/algorithmic-generalization-transformer-architectures/blob/52dd950dce8d32a8e72513999cac5a310e01ca53/experiments/model.py#L675-L842)

**两条路径的训练目标有实质差别。** 在同权重、同一组教师输入、关闭 dropout 和扰动且轮数相同的条件下，若一批有 T 轮，去掉首轮 VALUE 加倍的慢路径损失等于 fast 损失乘 T。原始慢路径还要再加一份首轮 VALUE 损失，涉及该轮所有位置的 VALUE 监督。因此梯度既有整体尺度差异，也有首轮数值监督的相对权重差异。归档的 `tmp/scripts/grad_consistency.py` 用一个 batch 关掉 dropout 做梯度对照，其中去掉首轮加倍的比较仍直接拿两组梯度算相对 L2。应先把慢路径梯度除以 T，再检查差异。真实训练开启了 dropout，合批还可能改变随机数消耗顺序。单批检查和最终准确率属于两个层面，后者还需要配对训练。

**快慢开关直接作用于训练，raw 和 clean 在评估时切换。** 训练中的离散验证统一调用慢路径的损失函数，每个 batch 随机选择教师输入或自主回灌。独立评估对同一权重只按指定口径逐轮回灌，因此同一权重的 raw / clean 差异可以直接归到辅助因子开关。要量化训练快慢路径对最终成绩的影响，应固定 L2H16D256、初始权重、数据顺序和种子，关闭纠错，成对训练后用同一冻结集评估。如果只想测合批方式本身，还需要先对齐首轮权重和跨轮归一化。 [训练验证](https://github.com/Awni00/algorithmic-generalization-transformer-architectures/blob/52dd950dce8d32a8e72513999cac5a310e01ca53/experiments/model.py#L350-L370)

比较训练日志时还要留意，fast 的 VALUE 日志在循环里用筛选过的位置覆盖了 `correct`，后续轮的逐 token 和整序列日志可能读取错误的数组。损失在此之前已经算好，受影响的是这两类日志。快慢路径的性能对照应以同一独立评估脚本的结果为准。 [训练日志计算](https://github.com/Awni00/algorithmic-generalization-transformer-architectures/blob/52dd950dce8d32a8e72513999cac5a310e01ca53/experiments/model.py#L539-L605)

## 数据生成与下一步

随包提供的四个数据文件共 **2,274 张图**。逐题重算确认其模 23 标签、拓扑顺序、节点深度、父节点索引与填充一致，按完整 token 序列比较也没有组内或组间完全重复题。附件中正式训练集、16 档冻结集和压力集只有配置、记录或指标汇总。正式结果的逐题前向复跑需要对应数据与 checkpoint。

1. **固定标准集的生成记录。** 标准生成器目前没有独立的数据 seed 参数。每个 split 应保存生成参数、随机种子、文件哈希和实测深度分布。当前路径实际限制图深度的是 `max_depth`。
2. **把压力集生成和评估接起来。** v2 使用同一条随机流。以 seed 20261107 按 `chain110 → chain122 → mid60 → wide8` 重建采样，可匹配四池归档的深度、层宽和平均非填充长度。生成器写 `testdata_N128deep_<label>.pt`，评估器读取 `testdata_N<数字>.pt`。应记录或自动执行文件名映射，元数据分别保存池编号与真实节点数。
3. **分开验证选模与纠错归因。** 给 B 留一份未参与筛权重的 N=128 冻结集。用相同的 L4H16D384、fast 路径、训练数据和种子，只切换 VALUE 扰动训练。A-L4fast 可提供四层无纠错的参考，它与 B 仍有隐藏维度差异。随后单独评估受控数值扰动后的节点恢复与下游轨迹。
4. **补齐后续复现。** M1–M4 基线、注意力检索与模加的机制复现、C 线连续潜状态纠错，以及超过 128 节点的词表和规模扩展均待完成。
