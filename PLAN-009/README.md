# PLAN-009 草稿　对齐训练量后，比较离散与连续循环模型如何更新已算结果

**研究问题。** 一个已算对的中间值被改错后，受测的原始连续模型 C 有时会重新算对，接受纠错训练的离散 B 也会，离散 A′ 在部分相同题目上会保留错值。三者的训练长度、权重选取时点和同题拟合水平有差异。本计划先补齐训练预算，再比较哪种更新行为能跨种子、跨场景复现，最后追问这些行为靠什么计算实现。

| 状态表示 | 常规训练 | 加入纠错训练 |
| --- | --- | --- |
| 离散字段回灌 | A′ | B |
| 连续隐藏向量回灌 | 原始 C | D，参照 B 的污染设置从头训练 |

### 1. 先续训 A′、B

现有主系列共用 L4H16D384 骨干和同一批模 23 训练图。A′、B 原训练 100 个周期，原始 C 已有 150 个周期的训练记录。建议 A′、B 沿用各自原配方续到**累计 150 个周期**。先用种子 42 的自有 A′、B-M6 对原始 C 42；种子 1234 是第二组候选，其 B 来自外部迁移，须注明来源并确认有可续训的完整保存点。现有离散 2025 和连续 2026 分列为各自家族的重复观测。[原始曲线与权重清单](../docs/records/2026-11-25/seed-training-curves.md)

起跑前核对实际训练集、验证集、恢复周期和优化器步数，记录权重身份。优先从训练末端的完整保存点恢复优化器及训练进度；若只有较早的完整保存点，从其实际周期续到同一终点并注明。保留固定周期权重、训练和验证曲线。建议保存 e143 和 e149，前者可以直接复核现有 C 主权重，后者对应训练满 150 个周期。正式测试题独立留出。训练期间即可推进第二步。

### 2. 在已有权重上设计并实现共用评测

| 评测 | 构造 | 主要读数 |
| --- | --- | --- |
| 干净求解 | 同题从空白开始。先做训练分布内基准，再分别改变深度、宽度和排列 | 标准轮及额外循环后的节点数值正确率、节点四字段全对率；父值齐备后仍有多少节点等待，整图何时完成 |
| 已算结果的保持与改写 | 同一图取正常待算、局部已算、整图已算三类起点，保留干净分支。分别改目标、改父值和同时改两者；连续替换加同值异来源对照 | 目标下一轮保留或改写了什么，原本正确的位置有多少被改坏 |
| 错误传播和持续恢复 | 在同一目标及其下游逐轮追踪。单独纳入模型自由求解时自然出错的轨迹 | 下游是否算出错值所特有的结果；在确有传播且留足观察轮数的题中，目标与下游是否一起持续回正 |

核心节点指标都以**变量定义的结果位置**为单位。第二项节点指标要求该处的语法、变量名、运算和数值四个字段同时与标签一致。每题先算比例，再对图等权，另保留原始计数；整图全对作为补充。用现有权重完成开发后，固定题目、取样规则、轮数、分母和选模规则。PLAN-008 的宽图配对、三种子恢复和随机预填可复用为诊断，正式确认使用独立图号。[PLAN-008](../PLAN-008/README.md)

### 3. 再确定 D 的训练配方

D 从头训练，继承 C 的连续回灌和基本监督，参照 B 在新可算位置引入数值错误。此阶段集中定三件事：在哪些位置和轮次有资格污染，怎样令连续向量表达预定错值，这种错值实际有多大概率被下游采用。B 的批次和位置抽样率是对齐起点，同时报告两边实际命中位置数、污染前读数和有效干预数。保留既有多时点、带中间 UPDATE 监督的后训练 C 作独立参照。D 的具体干预和训练开跑另行审定。

### 4. 做四组正式同题评测

第一张对照表固定训练量和推理轮数，分别看 B 相对 A′、D 相对 C 的变化，以及这两项变化是否随状态表示而异。第二张对照表用预先固定的独立验证题衡量自由求解拟合程度，比较拟合水平接近时，同一行为差异还剩多少。各家族自身的训练曲线与最终损失用于判断是否训到位，跨家族统一使用同题节点指标。保留各个种子的结果，并对达到同一起点的共同题集列出分母、实际轮次和干净对照。

### 5. 根据可复现的差异做机制分析

若“目标被改错时能够回正，父值被改错时又会破坏正确目标”稳定出现，就在同题上比较三种状态下的父值读取和结果写回：正常待算、已算且一致、已算且冲突。能区分假设的关键是**原本正确的位置是否也同样依赖这条重算路径**。针对候选读取或写回路径做阻断与补回，同时测正常求解、受扰恢复和正确结果保持。只有错点受到选择性影响时，再追踪冲突信号怎样改变后续更新。

**本轮审阅范围。** 确认 A′、B 续训的首批种子、恢复来源及固定保存周期。

跨家族比较前先读[损失路径与上游改动](../docs/records/2026-11-26/loss-paths-and-upstream-changes.md)：各家族走的是两条不同的损失路径，`total_loss` 绝对值不可跨家族比较。评测详细规格、D 配方和机制干预分别在后续阶段审阅。
